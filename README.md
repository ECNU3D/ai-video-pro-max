# AI 短视频创作技能库

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/ECNU3D/ai-video-pro-max
cd ai-video-pro-max

# 运行同步脚本，将 skills 链接到各 AI 工具的配置目录
./sync.sh
```

运行 `sync.sh` 后，技能文件会自动链接到以下目录：
- `.agent/skills` → Codex
- `.claude/skills` → Claude Code
- `.trae/skills` → Trae

**推荐使用 Trae + GLM-5**，获得最佳体验。[代码觉醒](./代码觉醒/) 示例项目就是用这套方案完成的。

### 支持的生成平台

**视频生成**：推荐使用 [即梦 Seedance 2.0](https://jimeng.jianying.com/)，同时支持：
- [海螺 Hailuo](https://hailuoai.com/video)
- [可灵 Kling](https://klingai.kuaishou.com/)
- [通义万相 Wanxiang](https://tongyi.aliyun.com/wanxiang/)
- [Vidu](https://www.vidu.studio/)

**图片生成**：推荐使用即梦，也支持任何文生图平台（如 Midjourney、Stable Diffusion、ComfyUI 等）。

> **提示**：本技能库支持首尾帧参考、全能参考等高级功能，适用于所有支持这些特性的视频生成平台。

---

一套完整的 AI 短视频创作工作流技能集，覆盖从故事构思、视觉规划、参考图提示词整理到视频分镜与生成前检查的全流程。

│         ↓                                                            │

## 各技能详解

### ① story-creator（故事创作助手）

| 项目 | 内容 |
|------|------|
| **用途** | 交互式引导用户从零创作完整的短视频故事 |
| **触发词** | "创作故事"、"编写剧本"、"短视频脚本" |
| **输入** | 用户的创意想法（或由系统随机生成） |
| **交互流程** | 收集创意 → 确认参数 → 生成大纲 → 角色设计 → 分集剧情 |
| **输出文件** | `{故事标题}.md` — 包含故事大纲、角色档案、分集剧情 |
| **下游技能** | → visual-director / 分镜技能 |

---

### ② visual-director（视觉总监）🆕

| 项目 | 内容 |
|------|------|
| **用途** | 在分镜生成之前，为故事创建统一的视觉设计文档 (VDD) |
| **触发词** | "视觉设计"、"色彩规划"、"视觉风格"、"VDD"、"画面风格" |
| **输入** | story-creator 的输出（故事大纲 + 角色 + 分集剧情） |
| **输出文件** | `{故事标题}-视觉设计文档.md` |
| **下游技能** | → scene-atmosphere / shot-rhythm-planner / 分镜技能 |

**输出内容 (VDD)**：

| 章节 | 说明 |
|------|------|
| 视觉基调 | 整体风格、画风前缀、主色调、横纵比 |
| 角色色彩身份 | 每个角色的主色/辅色/含义/状态变化色 |
| 场景色彩地图 | 每个场景的色温、主导色、光源、氛围 |
| 色彩叙事弧线 | 逐段/逐集的色彩变化计划 |
| 构图策略 | 角色构图语言、关系构图、情绪升级手法 |
| 光影设计 | 按场景的光源类型、方向、强度 |
| 视觉母题 | 贯穿全片的重复视觉元素 |

**核心价值**：用精准的场景画风前缀替代泛化的"高品质中国仙侠动漫风格，色彩鲜明，电影级光影，4K"。

---

### ③ scene-atmosphere（场景氛围设计师）🆕

| 项目 | 内容 |
|------|------|
| **用途** | 为每个场景生成多层次氛围卡片，输出可直接粘贴到分镜提示词的片段 |
| **触发词** | "场景氛围"、"氛围设计"、"场景细化"、"光影设计" |
| **输入** | 故事大纲（场景列表）+ 可选 VDD |
| **输出文件** | `{故事标题}-场景氛围卡片.md` |
| **下游技能** | → 分镜技能（提示词片段直接粘贴使用） |

**每张氛围卡片包含**：

| 层级 | 内容 |
|------|------|
| 视觉层 | 光源（类型/色温/方向/强度）、色调、对比度、三层纵深（前景/中景/背景）、质感纹理、粒子效果 |
| 听觉层 | 环境音、情绪音效、配乐方向 |
| 情绪映射 | 基调、与角色关系、叙事功能 |
| **AI提示词片段** | 光线片段、氛围片段、音效片段、**风格替换尾缀**（直接替代通用风格描述） |

---

### ④ shot-rhythm-planner（镜头节奏规划师）🆕

| 项目 | 内容 |
|------|------|
| **用途** | 在写分镜提示词之前，规划整集的镜头序列 |
| **触发词** | "镜头规划"、"节奏设计"、"分镜规划"、"景别分配" |
| **输入** | 故事大纲 + 每集目标时长 + 类型风格 + 目标平台 |
| **输出文件** | `{故事标题}-{集数}-镜头节奏规划.md` |
| **下游技能** | → 分镜技能（按规划表的镜头数/时长/景别/运镜生成提示词） |

**输出内容**：

| 章节 | 说明 |
|------|------|
| 节奏概览 | 总时长、镜头数、节奏类型 |
| 节奏曲线 (ASCII) | 可视化的时长分布图 |
| 逐镜规划表 | 每镜的时长/景别/运镜/动静/叙事功能/节奏意图 |
| 景别分布分析 | ECU/CU/MS/FS/LS 数量占比 vs 类型理想值 |
| 运镜分布分析 | 各运镜类型数量，标记过度重复 |
| 张弛标注 | 张力积累段、爆发点、呼吸空间 |
| 平台适配 | 根据目标平台时长限制自动调整 |

**支持的平台约束**：Seedance (4-15s) / Hailuo (6s或10s) / Wanxiang (5/10/15s) / Vidu (4-8s)

### ⑤ 分镜脚本生成（四选一）

根据目标视频平台选择对应技能：

| 技能 | 平台 | 每镜时长 | 特色 |
|------|------|---------|------|
| **seedance-storyboard** | 即梦 Seedance 2.0 | 4-15s | 叙事模式、首尾帧参考、参考素材审查 |
| **hailuo-storyboard** | 海螺 AI | 6s / 10s | 时间序列运镜、高级公式 |
| **wanxiang-storyboard** | 通义万相 2.6 | 5/10/15s | 多机位模式、美学优先、@角色引用 |
| **vidu-storyboard** | Vidu | 4-8s | 动态控制关键词、艺术风格丰富 |

| 项目 | 内容 |
|------|------|
| **输入** | 故事/剧本文字 + 可选 VDD + 可选氛围卡片 + 可选节奏规划 |
| **输出文件** | `{主题}-{平台}分镜脚本.md` |
| **下游技能** | → storyboard-reviewer / reference-image-prompt-polisher |

### ⑥ storyboard-reviewer（分镜审片师）🆕

| 项目 | 内容 |
|------|------|
| **用途** | 对已完成的分镜脚本进行 8 维度专业审查，评分并给出具体修改建议 |
| **触发词** | "审查"、"审片"、"分镜审查"、"质量检查"、"review" |
| **输入** | 分镜脚本 Markdown 文件 + 可选 VDD |
| **输出文件** | `{标题}-审片报告.md`（如用户同意自动修改，还会输出 `{标题}-分镜脚本(已修订).md`） |

**8 个审查维度及权重**：

| 维度 | 权重 | 审查要点 |
|------|------|---------|
| 提示词质量 | 20% | 风格尾缀差异化、光线描述、纵深层次、质感/粒子 |
| 节奏分析 | 15% | 时长分布变化性、高潮段是否加速、呼吸空间 |
| 景别分布 | 15% | ECU/CU/MS/FS/LS 占比是否合理 |
| 运镜多样性 | 12% | 运镜类型种类和分布 |
| 构图意图 | 12% | 是否有空间安排、人物位置、光影方向指导 |
| 色彩连续性 | 10% | 色调过渡、角色色彩身份维护（需 VDD） |
| 视觉连续性 | 10% | 同场景光线一致、角色外观一致、时间连贯 |
| 叙事完整性 | 6% | 叙事弧线是否完整覆盖 |

**评级**：A+(95+) / A(90-94) / B+(85-89) / B(80-84) / C+(75-79) / C(70-74) / D(<70)

### ⑦ reference-image-prompt-polisher（参考图提示词整理器）🆕

| 项目 | 内容 |
|------|------|
| **用途** | 将粗糙的人物、场景、首帧、尾帧或整段分镜描述，整理为适合文生图/参考图生图的高质量中文提示词，并默认保存为 Markdown 文件 |
| **触发词** | "润色提示词"、"人物参考图"、"场景参考图"、"三视图"、"四宫格场景"、"首尾帧提示词" |
| **输入** | 分镜脚本、角色/场景描述、首尾帧粗描述、已有提示词、可选 VDD |
| **输出文件** | `{主题关键词}-参考图提示词.md` |
| **下游技能** | → gemini-batch-imagegen / 其他图像生成工作流 |

**在整体流程中的作用**：

| 场景 | 产出 |
|------|------|
| 角色设定统一 | 主参考图提示词 + 三视图整合图提示词 |
| 场景空间统一 | 场景主视图提示词 + 四方向四宫格整合图提示词 |
| 视频关键帧准备 | 首帧提示词 + 按需输出尾帧提示词 |
| 素材归档 | 自动保存为 Markdown，便于后续批量出图或手动复用 |

| 项目 | 内容 |
|------|------|

| **触发词** | "生成参考图"、"角色设定图"、"场景图"、"batch imagegen" |
| **输入** | `reference-image-prompt-polisher` 输出的 Markdown 文件、分镜脚本或角色/场景设定文档 |
| **输出** | 批量下载的 PNG 图片 + `manifest.md` 清单 |

### ⑨ video-transition-auditor（视频生成预检查）🆕

| 项目 | 内容 |
|------|------|
| **用途** | 在提交AI视频平台**生成前**，审查首帧图+可选尾帧图+提示词之间的一致性和迁移逻辑 |
| **触发词** | "预检查"、"验证首尾帧"、"检查提示词"、"生成前审核"、"帧词一致性" |
| **输入** | 首帧参考图 + 提示词 + 可选尾帧参考图 |
| **输出文件** | `{标题}-预检报告.md` + 修改后的提示词（如需修改） |

**两种检查模式**：

| 模式 | 输入 | 适用场景 |
|------|------|---------|
| 首帧模式 | 首帧图 + 提示词 | 仅使用首帧参考的视频生成 |
| 首尾帧模式 | 首帧图 + 尾帧图 + 提示词 | 使用首尾帧参考的视频生成 |

**5 个审查维度**：

| 维度 | 首帧模式权重 | 首尾帧模式权重 |
|------|-------------|---------------|
| 首帧-提示词一致性 | 35 | 20 |
| 尾帧-提示词一致性 | — | 20 |
| 首尾帧一致性 | — | 15 |
| 迁移逻辑完整性 | 40 | 25 |
| 提示词质量 | 25 | 20 |

**判定**：A(85+) 通过可生成 / B(70-84) 建议修改 / C(<70) 不通过必须修改

**核心价值**：生成一次视频成本不低，预检查在生成前拦截问题，避免浪费。

### ⑪ storyboard-diagram（分镜镜头移动示意图）🆕

| 项目 | 内容 |
|------|------|
| **用途** | 从视频分镜脚本生成 Remotion 动画，可视化展示每个分镜的摄像机位置、主体移动路径、环境特征 |
| **触发词** | "镜头示意图"、"分镜动画"、"摄像机移动图"、"分镜可视化" |
| **输入** | 分镜脚本 Markdown 文件 |
| **输出** | Remotion 项目（可预览、可渲染为视频） |

**何时使用**：

| 场景 | 说明 |
|------|------|
| 分镜规划验证 | 在提交 AI 视频平台前，可视化验证镜头移动逻辑是否合理 |
| 团队沟通 | 向导演/摄影师展示镜头设计意图 |
| 文档归档 | 为分镜脚本生成配套的可视化示意图 |
| 教学演示 | 展示不同运镜方式（推/拉/跟随）的效果 |

**工作流程**：

```
1. 解析分镜脚本 → 提取景别、运镜、主体、环境
2. 创建 Remotion 项目 → python3 scripts/init_project.py <路径>
3. 配置分镜数据 → 编辑 src/shotData.ts
4. 创建分镜组件 → 编辑 src/Shots.tsx
5. 注册到 Root → 编辑 src/Root.tsx
6. 预览渲染 → npm run dev
```

**启动 Remotion Studio**：

```bash
# 进入项目目录
cd <项目路径>/storyboard-diagrams

# 启动开发服务器
npm run dev

# 浏览器访问
# http://localhost:3000
```

**渲染为视频**：

```bash
# 渲染单个分镜
npx remotion render Shot01-城市全景 out/shot01.mp4

# 渲染所有分镜
npx remotion render AllShots-完整预览 out/all-shots.mp4
```

**输出内容**：

| 元素 | 说明 |
|------|------|
| 镜头 FOV 锥形 | 红色三角形，表示摄像机视场范围和朝向 |
| 镜头移动路径 | 红色虚线，表示摄像机移动轨迹 |
| 主体位置 | 蓝色圆点，带标签显示主体名称 |
| 主体移动路径 | 蓝色虚线，表示主体移动轨迹 |
| 环境元素 | 灰色矩形/圆形，表示建筑、设备、标记点等 |
| 信息面板 | 左上角显示分镜编号、景别、运镜、时长 |

**核心概念**：

- **坐标系**：原点在场景中心，Y 轴向下为正
- **FOV 方向**：自动计算（lookAt > 移动方向 > 主体位置）
- **动画驱动**：所有动画由 `useCurrentFrame()` 驱动

## 快速开始示例

### 场景 A：完整流程（最高质量）

```
你：帮我创作一个修仙题材的短视频故事               → story-creator
你：帮这个故事做视觉设计                           → visual-director (输出 VDD)
你：帮我设计每个场景的氛围                         → scene-atmosphere (输出氛围卡片)
你：帮我规划第1集的镜头节奏，目标120秒，用Seedance  → shot-rhythm-planner (输出节奏规划)
你：根据以上材料生成Seedance分镜                    → seedance-storyboard (输出分镜脚本)
你：审查一下这个分镜                               → storyboard-reviewer (输出审片报告)
你：按建议修改                                     → 自动修改分镜脚本
你：把人物/场景/首尾帧提示词整理成文档              → reference-image-prompt-polisher (输出提示词md)
你：根据提示词文档批量生成参考图                    → gemini-batch-imagegen (输出参考图)
你：帮我检查这组首帧+提示词能不能用                 → video-transition-auditor (预检报告)
你：通过了，提交生成                               → 粘贴到AI视频平台
```

### 场景 B：快速出片（跳过预规划）

```
你：把这段剧情转成Seedance分镜     → seedance-storyboard (直接生成分镜脚本)
你：审查一下                       → storyboard-reviewer (发现风格尾缀统一等问题)
你：自动修改                       → 按建议优化分镜脚本
```

### 场景 C：仅做视觉规划

```
你：我有个故事大纲，帮我做视觉设计   → visual-director (输出 VDD)
你：再细化每个场景的氛围             → scene-atmosphere (输出氛围卡片)
```

### 场景 D：分镜可视化验证 🆕

```
你：帮我把这个分镜脚本转成镜头移动示意图   → storyboard-diagram (创建 Remotion 项目)
你：启动预览看看效果                       → cd storyboard-diagrams && npm run dev
你：渲染成视频                             → npx remotion render AllShots-完整预览 out.mp4
```

| Ch.7 色彩 | 色彩身份、叙事弧线、暖冷对比、饱和度策略、色彩方案 | ② visual-director, ③ scene-atmosphere |
| Ch.5 扩展画面 | 运镜表达、关键帧vs扩展帧 | ④ shot-rhythm-planner |
| Ch.3 文字/图像 | ECU-LS 景别体系、运镜术语、镜头拍摄程序表 | ④ shot-rhythm-planner, ⑥ storyboard-reviewer |
| Ch.4 屏幕横纵比 | 画幅选择与叙事风格的关系 | ② visual-director |
| Ch.8 透视 | 一点/两点/三点透视、深度错觉 | ② visual-director |
