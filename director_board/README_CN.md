# 🎬 导演调度台

一款基于 360° 全景图编排导演走位参考的 Web 工具。加载全景图，在场景中放置彩色 3D 人体模型并调整姿态，框定镜头，然后导出平面 PNG——该图片可直接输入视频生成模型（如 Seedance），确保角色位置精确。

![导出画面](e2e/__screenshots__/export.png)

## 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
```

首次运行时会自动加载内置示例全景图（`public/example.png`）。

## 使用说明

- **环视 / 缩放** — 拖拽画布旋转视角；鼠标滚轮调节视野（全景缩放）。
- **上传全景图** — 加载你自己的等距柱状投影（2:1）360° 图片，或点击 *Load example*。
- **添加角色** — 在摄像机前方生成一个可摆姿态的彩色人体模型。
- **选择** — 点击场景中的人偶，或点击侧边面板中的对应行。
- **移动 / 旋转 / 缩放** — 在工具栏选择模式，然后拖拽控制手柄。移动沿地面滑动，旋转可在**任意轴**上转动（偏航控制朝向，俯仰/翻滚可倾斜人偶），缩放等比调整大小。姿态、颜色、尺寸、高度和旋转（偏航/俯仰/翻滚）也可以在侧边面板中编辑。
- **姿态** — 站立、坐姿、行走、蹲姿、指向、举臂、躺姿。
- **让人躺下** — 直接选择**躺姿**（一键平躺），或对任意姿态用控制手柄/滑块将**俯仰**调至 90°。然后调高**高度**让人偶落在床或沙发上，再用**偏航**对齐方向。
- **导出 PNG** — 渲染一帧干净画面（隐藏网格、控制手柄和选中光环）并下载。
- **保存 / 加载** — 将整个构图（全景图引用、每个角色的颜色/姿态/位置/旋转/缩放以及摄像机状态）保存为 JSON 项目文件，之后可重新加载。

## 实现原理

使用一个大型内翻球体（`THREE.BackSide`）贴上等距柱状投影图片作为全景。摄像机位于球心附近、眼高（1.6）处；`OrbitControls` 控制视角旋转，滚轮驱动 FOV。人体模型由基本几何体程序化构建，通过逐关节旋转摆出姿态，站立在虚拟地面 `y = 0`。选中一个人偶后会挂载 drei 的 `TransformControls` 控制手柄，变换数据写回 zustand 状态仓库。

> 注意：2D 全景图没有真实深度信息，因此人偶大小需通过手动缩放/移动来匹配场景。这是 v1 的设计意图。

## 技术栈

Vite · React 19 · TypeScript · three.js · @react-three/fiber · @react-three/drei · zustand。使用 Vitest（纯逻辑）和 Playwright（无头 WebGL + 截图校验）进行测试。

## 脚本

```bash
npm run dev         # 开发服务器
npm run build       # 类型检查 + 生产构建
npm test            # 单元测试 (Vitest)
npm run e2e         # 端到端测试 (Playwright)
```

## 项目结构

```
src/
  three/      全景球体、人体模型、场景、摄像机/FOV 控制
  store/      zustand 场景状态仓库
  data/       调色板、姿态预设
  lib/        项目序列化/解析、PNG/JSON 导出
  ui/         工具栏、侧边面板
docs/superpowers/   设计规格 + 实施计划
e2e/                Playwright 测试用例 + 截图
```
