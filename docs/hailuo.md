海螺AI视频生成界面​

无论你是初次接触AI的新人，还是已经能够熟练使用AI赋能生产力的老手，通过清晰的结构和灵活的表达方式，都可以轻松掌握Prompt的编写技巧，实现“一个人 + 一个AI = 一个专业剧组”的科幻愿景。只要掌握一些小小的规则，人人都可以成为AI魔法师！​

为了达到更好的表现效果，我们为大家设计了两类 Prompt的参考公式：​

1、Prompt基础公式​

Prompt基础公式适用于对于视频没有明确的镜头呈现需求，或者期待使用AI视频激发创作灵感的朋友，自由的Prompt可以获得更具想象力的画面。​

❤️

Prompt基础公式= 要创建的主要表现物 + 场景空间 + 运动 / 变化​

要创建的主要表现物：主要表现物是视频的核心信息，可以是人物、动物、其它物体亦或是不存在的想象之物。​

场景空间：场景空间描述的是视频表现物的周围环境信息，可以是精确的标志性空间，如图书馆、咖啡厅，也可以是幻想性的虚构场景。​

运动/变化：运动和变化是对于主要表现物在视频中的状态描述，例如物体的静止、运动；环境空间的转化等等。​

例如：​

一只小狗 在公园 中 奔跑​

一个女人 打着伞 在 雨中的街头 行走​

山谷中 的 一条小溪 静静 流淌​

2、Prompt精确公式​

Prompt精确公式适用于对于镜头运动或画面呈现有明确需求，需要更加专业视频输出物的用户，准确细致的Prompt能够提供更加准确、更具美感的视频画面。​

❤️

Prompt精确公式= 要创建的主要表现物 + 场景空间 + 运动 / 变化 + 镜头运动 + 美感氛围 ​

镜头运动：镜头运动可以限定视频画面的呈现方式，可以使用常见的镜头运动方式，例如 推、拉、摇、移、升、降等镜头运动方式，对画面呈现效果进行限定。​

美感氛围感：可以对画面呈现的视觉风格、画面氛围感进行限定，可以得到更加符合预期的表现效果。​

例如：​

一对情侣 坐在 公园的长椅上 交流，镜头维持固定 拍摄情侣，画面色调偏暖，氛围温馨​

一只小羊 在 一片草地 里 低头吃草，镜头缓缓推进 小羊，画面色调自然写实​

一个身穿西装的男人 面色凝重地 在 面馆 里 吃面，镜头逐渐拉远 展示 面馆的吵闹环境，画面色调自然​

3、Prompt公式的使用技巧​

上述两类Prompt公式并非是严格的使用准则，与AI的每一次对话都可能产出不同的效果。但总体来说，Prompt写作还是遵循两个主要的基本原则：​

•

更精确的表达可以带来更准确的视频信息呈现​

•

更丰富的表达可以带来更好的视频生成效果​

我们将在后面内容更详细地讲解。​

进阶 - 实现精准的画面控制和表现​

精准的镜头控制​

海螺AI能够有效地响应多种类型的镜头运动，能够为有明确镜头运动需求的专业视频用户提供更多选择。​

为了实现更加精准和更具美感的镜头的运动，可参考以下几个小技巧：​

❤️

•

为镜头运动增加更精确的时序：可以获得更加精确，更大镜头动态的视频。​

例如“镜头旋转下降” 可以优化为 ：​

“镜头先缓缓下降，之后在下降的过程中向右环绕。”​

•

为镜头运动带来的画面变化增加更细致的描述：可以获得更精确，更具美感的镜头运动画面。​

例如 “镜头从下往上拍摄长颈鹿” 可以优化为：​

“镜头由长颈鹿的脚部特写开始，缓缓上升，拍摄到长颈鹿的身体，最后停留在长颈鹿的面部，近景展示长颈鹿的面部表情。”​

•

将镜头运动的时长合理控制在5-6秒之内：避免过度复杂的镜头导致生成失败。​

### **图生视频Prompt公式**

#### **1、图生视频Prompt基础公式**

图生视频使用的图片作为视频的首帧出现，限定了视频的主体形象和基本画面美学风格，因此相比文生视频Prompt，图生视频Prompt可以适当地减少信息量。

> ✅ **图生视频Prompt基础公式 = 首帧中的主要表现物 + 运动/变化**
> * **首帧中的主要表现物：** 即画面中的物品，包括主要信息和环境信息，海螺AI能够精确识别图像中的人物、物品等画面信息，并根据Prompt需求进行视频生成。
> * **运动/变化：** 运动和变化是对于主要表现物在视频中的状态描述，例如物体的静止、运动，环境空间的转化等等。
> 
> 

**例子：(使用图片由Midjourney生成)**

| 图片内容 | 基础Prompt |
| --- | --- |
| (小狗在床上) | 画面中的小狗狗，眼中发出蓝光，小狗狗面前凌乱的衣服也发出蓝光慢慢飘起，然后自动在空中折叠整齐，落在小狗狗面前，之后小狗狗眼中的蓝光消失了。 |
| (蓝色毛绒生物煮饭) | 画面中的蓝色毛绒生物不断搅动着面前的汤锅，汤锅冒着热气，之后蓝色怪物对着面前的锅吹起，面前的汤碗结成冰块。 |

#### **2、图生视频Prompt精确公式**

在基础公式上补充镜头信息和氛围感信息可以更加精确控制视频，生成动态更强或风格化更明显的视频。

> ✅ **图生视频Prompt精确公式 = 首帧中的主要表现物 + 运动/变化 + 镜头运动 + 美感氛围变化**
> * **镜头运动：** 图生视频同样可以精确控制镜头运动，将画面中的信息作为参考物写作Prompt可以获得更加精确的结果。
> * **美感氛围变化：** 尽管首帧已经确定了视频开头的画面氛围色调，但海螺AI图生视频依旧能够对画面的美感氛围进行调整以产出更加符合预期的视频内容。
> 
>

| 图片内容 | 精确Prompt |
