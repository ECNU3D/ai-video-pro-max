# 文戏导演设计师

## Overview

把已经明确剧情目标的文戏，进一步设计成“谁在压制谁、什么时候反转、靠什么动作和环境升级气氛、如何避免静戏无聊”的导演文档。

核心原则：文戏不能靠炫技补剧情。先把人物博弈、环境情绪和对话节奏设计到位，再考虑平台分镜翻译。

生成前先阅读：
- `references/dialogue-template.md`：固定输出结构与章节要求
- `references/dialogue-checklist.md`：语速、人数、强弱转换、室内/室外与借景抒情检查清单

## Scope Decision

优先处理这些单位：

1. 单场对话戏：
最佳输入单位，最适合做完整文戏导演设计。

2. 借景抒情过场：
可处理，但重点转向环境、动作、情绪承接，不必强行写成密集对白戏。

3. 同一空间内连续文戏：
可以合并在一份文档中，但必须共享同一戏剧目标或同一情绪弧线。

4. 整集：
不要整集一起做。先拆出真正关键的对话戏、审讯戏、摊牌戏、室内遭遇戏、借景抒情戏分别处理。

如果输入只有情节概述而没有人物关系或台词目标，先标注“文戏设计信息不足”，不要假装已经能细做。

## Workflow Overview

按下面顺序执行：

1. 明确戏份类型与戏剧目标
2. 判断人物强弱关系与反转路径
3. 识别文戏类型：室内 / 室外 / 对话 / 借景抒情
4. 规划文戏基础模板的阶段
5. 确定语速关系、人数关系和代表角色
6. 设计动作、表情、间歇与环境升级
7. 规划高潮前戏、底牌与胜负落点
8. 输出文戏导演设计文档并要求人审

## Preferred Inputs

理想输入优先级：

1. `storyboard-blueprint` 输出的导演分镜蓝图
2. `continuity-blocking-planner` 输出的空间与 blocking 文档
3. 单场戏剧本 / 对白文本 / 文字分镜
4. 角色设定、VDD、场设或参考片

如果同时拿到多个来源，以导演蓝图和 blocking 文档为主，不要让平台分镜脚本里的表面写法替代文戏判断。

## Step 1: Define The Dramatic Core

先回答这些问题：

- 这场文戏真正要赢什么
- 谁想压制谁，谁想隐藏什么
- 对话是为了试探、羞辱、说服、拖延、威吓、反转，还是告别
- 观众在开场时应该相信什么
- 观众在结尾时应该改信什么

如果这些问题回答不清，说明这场戏还不能开始做导演设计。

## Step 2: Map Power Dynamics

文戏的核心抓手是强弱关系，不是对白字数。

至少写清楚：

- 开场谁强谁弱
- 强势来自身份、信息、语速、情绪稳定度还是空间位置
- 中间哪个点发生第一次强弱转换
- 是否存在第二次反转
- 最终谁赢，赢的方式是什么

强弱转换点必须绑定可拍的东西：

- 表情变化
- 手部动作
- 标志性肢体动作
- 台词节奏变化
- 环境光影或声音变化

## Step 3: Classify The Scene Type

先判断文戏属于哪一类：

- 室内文戏
- 室外文戏
- 纯对话戏
- 借景抒情戏
- 混合型

处理原则：

- 室内文戏：重物件、门口、家具、窗外、压迫感、小动作
- 室外文戏：重风景、天气、建筑、远近关系、借景抒情
- 纯对话戏：重语速、对话顺序、动作间歇、局部特写
- 借景抒情戏：重环境与人物情绪共振，不强行堆对白

## Step 4: Use The Dialogue Template

默认按文戏基础模板来设计，不要直接跳到散乱镜头建议。

优先按这些阶段组织：

1. 开端环境氛围
2. 对话开关
3. 初次交锋
4. 强弱转换点 1
5. 对话间歇
6. 标志性动作再出现
7. 环境氛围升级
8. 第二次交锋
9. 高潮前戏
10. 底牌前表情与气氛
11. 亮底牌
12. 胜负结果
13. 点题升华
14. 收尾 / 新灾祸开端

不必每场戏都机械写满 14 段，但至少要明确保留了哪些、删减了哪些、为什么。

## Step 5: Design Speech Rhythm And Cast Pattern

至少判断两类结构：

### A. 语速关系

- 双方匀速
- 一快一慢
- 先快后慢 / 先慢后快

不同语速关系要写清：

- 谁掌控节奏
- 谁更像在进攻
- 谁在防守或忍耐
- 反转点前后节奏如何变化
- 喜剧和悲剧取向是否不同

### B. 人数关系

- 一人对一人
- 一人对两人
- 一人对一群
- 群体对群体

多人戏必须标出：

- 主对话人
- 次对话人
- 谁只负责烘托
- 谁代表阵营发言

## Step 6: Add Motion Into Stillness

文戏不能一味站着说话。必须主动设计“静中的动”：

- 眼神变化
- 喝茶、咳嗽、放杯、整理衣角、捏拳、后退半步等标志性动作
- 对话间歇与冷场
- 局部动作特写
- 空镜插入
- 环境变化：风、雨、雷、门、窗帘、动物、灯光、室内物件

这些元素的作用必须明确：

- 是打断当前情绪
- 还是升级压力
- 还是暗示命运
- 还是制造反差

## Step 7: Output Rules

严格按 `references/dialogue-template.md` 的结构输出。

默认文件名：

- `{标题}-文戏导演设计.md`

如果没有明确标题，可用：

- `文戏导演设计.md`

文档必须包含：

- 戏剧目标
- 强弱关系图
- 场景类型判断
- 模板阶段取舍
- 语速与人数关系设计
- 动作 / 表情 / 间歇 / 环境设计
- 高潮与收尾判断
- 风险点与下游交接建议

## Review Gate

输出后先让用户审阅，重点确认：

- 强弱关系和反转是否对
- 哪个角色该压人，哪个角色该忍
- 是否需要更悲剧、更喜剧、或更阴狠
- 哪些环境元素要保留，哪些太重了

明确提醒：

- 这是一份文戏导演设计文档，不是最终平台提示词
- 如果通过，可交给平台分镜技能继续翻译
- 如需先再细化空间关系，可回到 `continuity-blocking-planner`

## Quality Bar

以下情况视为失败：

- 只复述对白内容，没有强弱判断
- 没有语速关系分析
- 没有人数关系处理
- 没有动作 / 表情 / 间歇设计
- 没有环境升级或借景抒情判断
- 机械套模板，没有写取舍理由
- 直接写成平台 prompt
