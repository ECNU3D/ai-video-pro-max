# 海螺 AI 分镜提示词生成器

## 概述

将用户输入的剧情或剧本，解析为一个或多个海螺 AI 视频分镜提示词，并将结果保存为 Markdown 文件。

## 工作流程

### 第一步：分析内容

读取用户输入，判断：

1. **情节复杂度** → 决定分镜数量（每个分镜建议对应6秒或10秒视频）
2. **场景与主体** → 提取关键人物、场景、动作、情绪
3. **叙事节奏** → 确定时间节点分配
4. **生成模式** → 文生视频或图生视频

**分镜数量参考：**

| 内容类型        | 建议分镜数 |
| ----------- | ----- |
| 单一场景 / 简单动作 | 1 个   |
| 2-3 个场景转换   | 2-3 个 |
| 完整短片 / 复杂叙事 | 4-6 个 |

### 第二步：选择提示词公式

- **基础公式**（场景简单、无明确镜头需求）：
  `主要表现物 + 场景空间 + 运动/变化`
- **精确公式**（需要专业镜头控制和美学效果，推荐）：
  `主要表现物 + 场景空间 + 运动/变化 + 镜头运动 + 美感氛围`
- **图生视频基础公式**（有参考首帧图片时）：
  `首帧中的主要表现物 + 运动/变化`
- **图生视频精确公式**（有参考首帧图片，需精确控制）：
  `首帧中的主要表现物 + 运动/变化 + 镜头运动 + 美感氛围变化`

### 第三步：构建每条提示词

每条提示词应包含（按优先级排列）：

1. **主要表现物**（必填）：人物特征、服装、表情，或场景主体
2. **场景空间**：地点环境、时间、氛围
3. **运动 / 动作**：主体的具体运动或变化状态
4. **镜头运动**（精确公式）：用时序描述，如"镜头先缓缓下降，之后向右环绕"
5. **美感氛围**（精确公式）：色调、视觉风格、画面氛围感

**镜头时序技巧（核心）：**

- 加入时序让镜头动态更大：`"镜头先缓缓下降，之后在下降过程中向右环绕"`
- 描述画面变化：`"由脚部特写开始，缓缓上升，到身体，最后停留在面部"`
- 单个分镜镜头运动控制在 **5-6 秒内**，避免过度复杂导致生成失败

**常用运镜词汇：**
推镜头 · 拉镜头 · 摇镜头 · 移镜头 · 升镜头 · 降镜头 · 固定镜头 · 俯拍 · 仰拍 · 环绕 · 跟随

### 第四步：输出并保存 Markdown 文件

**屏幕输出格式：**

```
---
【分镜 1 / N】建议时长：X 秒

[完整提示词，可直接复制粘贴]
---
```

**同时将结果保存为 Markdown 文件：**

- 文件名：`{主题关键词}-海螺分镜脚本.md`（如无明确主题，使用 `海螺分镜脚本.md`）
- 保存位置：当前工作目录
- 文件内容包含：标题、生成时间戳、用户原始输入摘要、所有分镜提示词

**Markdown 文件结构：**

```markdown
# {主题}-海螺分镜脚本

> 生成时间：{时间} | 分镜数：{N} | 平台：海螺 AI

## 原始输入

{用户输入的剧情/剧本摘要}

## 分镜提示词

### 分镜 1（建议时长：X 秒）

{完整提示词}

### 分镜 2（建议时长：X 秒）

{完整提示词}

---
*提示词格式适配：海螺 AI 文生视频 / 图生视频*
```

## 注意事项

- 每个分镜对应 **6秒或10秒**视频时长，镜头运动不宜过度复杂
- 更精确的描述 → 更准确的视频；更丰富的描述 → 更好的生成效果
- 图生视频：图片作为首帧，可减少主体和美学描述的信息量
- 镜头加入时序描述（先…之后…）可获得更大的镜头动态
