## 1. 提示词公式总览

### 文生视频基础公式
```
主要表现物 + 场景空间 + 运动/变化
```
适合无明确镜头需求、期望 AI 发挥创意的场景。

**示例：**
- `一只小狗 在公园 中 奔跑`
- `一个女人 打着伞 在 雨中的街头 行走`
- `山谷中 的 一条小溪 静静 流淌`

### 文生视频精确公式（推荐）
```
主要表现物 + 场景空间 + 运动/变化 + 镜头运动 + 美感氛围
```
适合对镜头运动或画面有明确需求的专业用户。

**示例：**
- `一对情侣 坐在 公园的长椅上 交流，镜头维持固定 拍摄情侣，画面色调偏暖，氛围温馨`
- `一只小羊 在 一片草地 里 低头吃草，镜头缓缓推进 小羊，画面色调自然写实`

### 图生视频基础公式
```
首帧中的主要表现物 + 运动/变化
```
图片作为视频首帧，已限定主体形象和基础美学，可适当减少信息量。

### 图生视频精确公式
```
首帧中的主要表现物 + 运动/变化 + 镜头运动 + 美感氛围变化
```

## 2. 运镜语言

### 基础运镜

| 运镜 | 写法示例 |
|------|----------|
| 固定镜头 | `镜头维持固定拍摄` |
| 推镜头 | `镜头缓缓推进` `镜头逐渐拉近` |
| 拉镜头 | `镜头逐渐拉远，展示全景` |
| 摇镜头 | `镜头向右摇移` `镜头快速右摇` |
| 移镜头 | `镜头横向移动` |
| 升镜头 | `镜头缓缓上升` |
| 降镜头 | `镜头缓缓下降` |
| 俯拍 | `镜头俯拍` `从高处俯视` |
| 仰拍 | `镜头仰拍` `低角度向上拍摄` |
| 跟随镜头 | `镜头跟随人物移动` |
| 环绕镜头 | `镜头围绕人物旋转` `镜头环绕盘旋` |

### 景别词汇

| 景别 | 说明 |
|------|------|
| 特写 | 面部或细节，强调情绪 |
| 近景 | 胸部以上，表情清晰 |
| 中景 | 膝盖以上，兼顾人物与环境 |
| 全景 | 完整展示人物与场景 |
| 远景 | 大范围环境，渺小人物 |

## 3. 美感氛围控制

### 色调

| 色调 | 效果 |
|------|------|
| 画面色调偏暖 | 温馨、惬意、温柔 |
| 画面色调偏冷 | 冷峻、神秘、疏离 |
| 色彩低饱和 | 阴郁、压抑、写实 |
| 色彩浓郁鲜艳 | 绚丽、生动、活力 |
| 自然写实 | 纪录片感，贴近现实 |
| 画面灰暗 | 压抑、紧张、悬疑 |

### 氛围感

温馨 · 惬意 · 阴郁 · 紧张 · 压抑 · 轻松 · 冷峻 · 诡异 · 恐怖 · 史诗 · 浪漫

### 视觉风格

写实 · 电影质感 · 动漫风格 · 赛博朋克 · 奇幻 · 武侠 · 纪录片风格

## 4. 镜头时序写法

海螺 AI 对带有时序描述的镜头运动响应更精准，动态更大。

### 写法原则

1. **加入顺序词**：先…之后…；开始…然后…；随着…
2. **描述画面变化**：镜头移动时画面中出现什么、消失什么
3. **控制在 5-6 秒**：避免过度复杂导致生成失败

### 对比示例

| 简单写法 | 带时序的优化写法 |
|----------|----------------|
| 镜头旋转下降 | 镜头先缓缓下降，之后在下降的过程中向右环绕 |
| 镜头从下往上拍摄长颈鹿 | 镜头由长颈鹿的脚部特写开始，缓缓上升，拍摄到长颈鹿的身体，最后停留在长颈鹿的面部，近景展示长颈鹿的面部表情 |
| 镜头环绕女战士 | 镜头开始缓缓下降，并围绕她盘旋，随着视角的变化，可以看到她手中的长剑，镜头继续环绕，从侧面滑过，逐渐拉近，捕捉到她坚定的侧脸 |

## 5. 完整示例精选

### 单场景基础（文生视频）

```
一个身穿西装的男人 面色凝重地 在 面馆 里 吃面，镜头逐渐拉远 展示 面馆的吵闹环境，画面色调自然
```

### 单场景精确（文生视频）

```
深蓝色的夜空下，高楼的屋顶上，城市的霓虹灯倒映在刚刚下过雨的水坑中。镜头从水中的倒影慢慢升起，穿过细雨，展现站在屋顶边缘的一个黑色身影。之后镜头继续升起，展示一望无垠的现代城市景观。最后，镜头定格，站在边缘的孤独身影凝视着城市，光与影的交错营造出一种冷峻的氛围。
```

### 复杂叙事（带完整镜头时序）

```
镜头一开始俯拍一片神秘的林中空地，一位身着盔甲的女战士独自站在空地中央。她的盔甲在月光下闪烁着银色的冷光，周围的树木投下斑驳的阴影。镜头开始缓缓下降，并围绕她盘旋，随着视角的变化，可以看到她手中的长剑在微微颤抖，剑身上还残留着未干的血迹。镜头继续环绕，从侧面滑过，逐渐拉近，捕捉到她坚定的侧脸。可以看到她微微咬紧的下唇，脸上几缕散落的头发被汗水浸湿，贴在额头上。随着镜头绕到她的正面，画面变得更加紧凑，焦点逐渐集中在她的脸上。镜头最终停在了她的正面特写，聚焦在她锐利的眼睛上。月光打在她的脸上，勾勒出她脸上的每一个细节。
```

### 美感氛围对比（同一场景，不同色调）

**阴郁版：**
```
镜头拍摄一个女性坐在咖啡馆里，女人抬头思考着，镜头缓缓移动拍摄到窗外的街道，画面色调灰暗，色彩低饱和，氛围阴郁。
```

**温暖版：**
```
镜头拍摄一个女性坐在咖啡馆里，女人抬头看着窗外，镜头缓缓移动拍摄到窗外的街道，画面呈现暖色调，色彩浓郁，氛围轻松惬意。
```

### 图生视频精确（参考首帧）

```
画面中的猫快速向镜头跑来，眼睛里冒出白色的电光，然后整个身体被电光包围，越跑越快，两边的景物快速向后飞去，两侧场景产生动态模糊形成散发白色光芒的时空隧道。
```
