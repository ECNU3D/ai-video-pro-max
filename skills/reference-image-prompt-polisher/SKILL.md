# Reference Image Prompt Polisher

用于把粗糙描述或已有提示词整理成更稳定、更清晰、更适合图像模型理解的中文提示词。

目标不是直接生成图片，而是为后续图像生成或视频生成准备高可用的参考图提示词，并尽量保证角色一致性、场景连续性和整体风格统一。

## 支持的输入

- 已有的人物、场景、首帧或尾帧粗提示词
- 单镜头描述、多个镜头、整段分镜或剧情段落
- 用户指定的风格词、媒介感、色彩倾向或参考关系
- 用户要求的输出约束，例如“只要提示词”“严格简洁”“保留原风格”

## 工作模式

根据用户输入先识别为以下模式之一：

- 润色已有提示词
- 只生成人物参考图提示词
- 只生成场景参考图提示词
- 只生成首帧提示词
- 生成首尾帧提示词
- 分镜拆解并生成完整参考图提示词
- 混合模式

## 核心流程

### 1. 识别任务目标

先判断用户究竟要：

- 润色现有提示词
- 从分镜里拆资产
- 只产出某一类参考图
- 输出解释加结果，还是只输出结果

### 2. 提取全局风格

- 用户明确指定风格时，直接保留并统一
- 用户只说“统一风格”时，从 [styles.json](references/styles.json) 里选择最匹配的预设
- 用户风格模糊时，基于题材推断一个最合适的预设，并在输出里写明推断结果

统一风格时至少覆盖这些维度：

- 媒介感
- 色彩倾向
- 光线逻辑
- 纹理与质感
- 构图倾向
- 连续性规则

### 3. 区分稳定元素和镜头特有元素

人物稳定元素：

- 年龄段
- 脸型
- 发型和发色
- 身形
- 服装逻辑
- 标志性配饰或道具
- 气质

人物镜头特有元素：

- 姿势
- 表情
- 动作
- 机位
- 当前光线状态

场景稳定元素：

- 地点类型
- 室内或室外
- 建筑或地形特征
- 季节、天气、时间段
- 核心空间结构
- 核心陈设
- 气氛与色调

场景镜头特有元素：

- 当前镜头角度
- 当前景别
- 当前人物位置
- 临时动作元素
- 当前局部光效

### 4. 决定输出哪些资产

默认遵守以下规则：

- 同一个重复人物只生成一次人物参考图提示词
- 同一个重复场景只生成一次场景参考图提示词
- 同一人物若服装形态完全不同，可拆成多个版本
- 同一场景若昼夜、季节或完整度差异极大，可拆成多个版本
- 首帧按镜头生成
- 尾帧只在必要时生成

人物参考图生成条件：

- 出现命名角色
- 存在反复出现的主要人物
- 同一角色跨多个镜头出现
- 用户明确要求人物参考图、三视图、角色设定图或定妆图

场景参考图生成条件：

- 同一地点在多个镜头中重复出现
- 场景本身很重要，需要统一空间结构和气氛
- 用户明确要求场景参考图

首帧生成条件：

- 用户希望为视频生成准备参考图
- 用户给了镜头或分镜
- 用户明确提到首帧
- 某个镜头的起始状态很重要

尾帧生成条件：

- 用户明确要求首尾帧模式
- 用户明确说需要尾帧
- 镜头结束状态对视频生成很重要
- 镜头设计为从 A 过渡到 B

如果用户只是要单张参考图，不要强行输出尾帧。

### 5. 生成提示词

所有提示词尽量按这个顺序组织：

1. 图片用途
2. 主体
3. 场景
4. 当前状态或动作
5. 构图与机位
6. 光线与氛围
7. 风格
8. 一致性约束
9. 画面清洁约束

## 资产级规则

### 人物参考图

目标：

- 稳定人物身份
- 明确造型
- 为后续视频生成提供一致性基准

默认规则：

- 默认全身
- 默认干净背景
- 默认中性站姿
- 默认光线均匀
- 默认无文字无水印
- 默认突出轮廓和服装层次
- 默认优先生成一张正面全身的主参考图，再基于这张图生成三视图整合图
- 默认不要把不同视角拆成多套独立提示词或多张独立图片，除非用户明确要求按视角分别出图

人物参考图默认分两步思考：

1. 先生成主参考图提示词
2. 再生成三视图整合图提示词

主参考图提示词用于先生成一张单人、正面、全身、纯净背景的人物锚点图。这个阶段的重点是把脸、发型、服装、体型和标志性道具固定下来。

三视图整合图提示词用于在已经有主参考图的前提下，基于该图作为人物参考，再生成一张包含多个视角的角色设定图。默认是一张图内包含正面、侧面、背面；如果用户明确需要，也可以改成正面、四分之三侧、侧面、背面，但仍然是一张图，不是多张独立图。

如果用户明确提到三视图，默认输出：

- 一条主参考图提示词
- 一条三视图整合图提示词

如果用户提到人物参考图、角色设定图或定妆图，但没明确视图数量，默认输出：

- 只要单角色锚点时，输出一条主参考图提示词
- 如果上下文明显是在为视频一致性或设定图做准备，再补一条三视图整合图提示词

三视图整合图提示词里要明确这些约束：

- 基于已生成的正面全身主参考图作为唯一人物参考
- 同一张图中展示多个视角
- 保持同一人物身份、脸型、发型、服装和配色一致
- 不要生成多个人物，不要让不同视角看起来像不同角色
- 背景保持简洁，重点服务角色结构展示

### 场景参考图

目标：

- 固定环境气质
- 固定空间结构
- 固定时间、天气和色调
- 为后续视频保持环境连续性

默认规则：

- 没必要时不要放人物
- 强调前景、中景、背景层次
- 强调空间可读性
- 强调时间、天气和光线逻辑
- 默认优先生成一张场景主视图参考图，再基于这张图生成四个方向的四宫格整合图
- 默认不要把四个方向拆成四套独立提示词或四张独立图片，除非用户明确要求逐方向分别出图

场景参考图默认分两步思考：

1. 先生成场景主视图提示词
2. 再生成场景四宫格整合图提示词

场景主视图提示词用于先生成一张最能代表该环境的主锚点图。这个阶段的重点是把地点类型、空间结构、时间天气、主要材质、光线逻辑和整体气氛固定下来。

场景四宫格整合图提示词用于在已经有场景主视图的前提下，基于该图作为环境参考，再生成一张包含四个方向的环境设定图。默认是一张图内展示同一地点的四个方向视角，用于补足空间结构和方向关系，而不是生成四张彼此独立的图。

如果用户明确提到场景四宫格、四个方向、环境设定图、空间方向图，默认输出：

- 一条场景主视图提示词
- 一条场景四宫格整合图提示词

如果用户提到场景参考图，但没明确说要四个方向，默认输出：

- 先输出一条场景主视图提示词
- 如果上下文明显是在为视频连续性、环境搭建或空间统一做准备，再补一条场景四宫格整合图提示词

场景四宫格整合图提示词里要明确这些约束：

- 基于已生成的场景主视图作为唯一环境参考
- 同一张图中展示同一地点的四个方向
- 保持同一地点的建筑结构、地形关系、材质、时间、天气、光线和色调一致
- 四个方向之间要能互相印证空间关系，不要变成四个不同地点
- 背景与陈设可以因视角变化而不同，但核心空间骨架必须稳定
- 如果场景里允许出现人物，人物只能作为比例参照，不得喧宾夺主

### 首帧

目标：

- 定义镜头开始时的画面状态
- 明确主体位置、动作起点、场景结构和镜头语言
- 让后续视频生成更容易起步

### 尾帧

目标：

- 明确镜头结束时的画面状态
- 与首帧形成自然过渡关系
- 保持人物、场景和风格连续

## 输出规则

### 统一写法原则

- 优先写清楚，不堆砌空泛形容词
- 优先保证主体、轮廓、背景和空间关系可读
- 分层表达主体、环境、状态、构图、风格和约束
- 润色时保留原意，不擅自改变人物身份、年龄感、服装核心设定、发型、核心道具、场景类型和关键叙事动作
- 如果用户同时给了角色参考、环境参考和风格参考，明确各自作用

### 默认负面约束

如果用户没有要求单独输出 negative prompt，在提示词末尾用一句简洁约束概括即可，例如：

- 无文字
- 无水印
- 无多余人物
- 无畸形肢体
- 无模糊面部
- 无杂乱背景
- 无重复主体

只有在用户明确要求时，才单独输出 `negative prompt` 字段。

### 默认输出顺序

1. 统一风格说明
2. 人物参考图提示词
3. 场景参考图提示词
4. 首帧提示词
5. 尾帧提示词（仅在需要时）

默认输出模板：

```md
### 统一风格说明
- 风格名称：
- 媒介感：
- 色彩倾向：
- 光线逻辑：
- 纹理与质感：
- 连续性规则：

### 人物参考图提示词
#### 角色 1
（提示词正文）

### 场景参考图提示词
#### 场景 1
（提示词正文）

### 首帧提示词
#### 镜头 1 首帧
（提示词正文）

### 尾帧提示词
#### 镜头 1 尾帧
（提示词正文）
```

如果用户明确说“只要提示词”，不要输出分析或解释。

如果用户明确说“严格简洁”，压缩说明文字，只保留必要字段和提示词正文。

### 默认保存规则

生成完成后，除了在对话中输出结果，还必须将最终提示词保存为 Markdown 文件。不要只在聊天里给出结果而不落盘，除非用户明确要求“不要保存文件”。

默认保存约定：

- 保存格式：`.md`
- 保存位置：当前工作目录
- 默认文件名：`{主题关键词}-参考图提示词.md`
- 如果没有明确主题关键词，使用 `参考图提示词.md`
- 如果输入本身来自某个已知 Markdown 或文本文件，优先使用源文件名作为前缀，例如 `{源文件名}-参考图提示词.md`

保存的 Markdown 文件至少包含这些部分：

- 标题
- 生成时间
- 用户原始需求摘要
- 统一风格说明
- 人物参考图提示词
- 场景参考图提示词
- 首帧提示词
- 尾帧提示词

如果某一类内容本次没有生成，就不要在文件里保留空章节。

建议的文件结构：

```md
# {主题关键词}-参考图提示词

> 生成时间：{时间}

## 原始需求摘要

{用户输入摘要}

## 统一风格说明

{风格说明}

## 人物参考图提示词

{人物相关提示词}

## 场景参考图提示词

{场景相关提示词}

## 首帧提示词

{首帧提示词}

## 尾帧提示词

{尾帧提示词}
```

## 质量自检

输出前检查：

- 是否保持用户原意
- 是否统一风格
- 是否对重复角色去重
- 是否对重复场景去重
- 是否只在必要时输出尾帧
- 是否让人物参考图更适合做一致性资产
- 是否让场景参考图更适合做环境资产
- 是否让首尾帧之间具有自然衔接关系
- 是否避免空泛堆词
- 是否保持中文输出自然、专业、可直接使用
- 是否已经将最终结果保存成 Markdown 文件
