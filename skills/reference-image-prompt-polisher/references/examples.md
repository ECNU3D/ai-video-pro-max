# 参考图提示词生成与润色 - 示例

## 示例 1：把粗糙人物提示词润色成三视图参考图

### 用户输入
帮我把这个人物提示词润色成适合做三视图参考图的版本，统一成水彩童书风格：
“一个八九岁的小女孩，短发，穿黄色雨衣，背着红色小书包，很勇敢。”

### 预期输出要点
- 输出统一风格说明
- 输出两条人物相关提示词：主参考图提示词 + 三视图整合图提示词
- 三视图整合图是一张图，不是按正面、侧面、背面拆成多张
- 保留黄色雨衣和红色书包这两个稳定锚点
- 三视图整合图要写明“基于已生成的正面全身主参考图继续生成”

## 示例 2：把粗糙场景描述润色成场景参考图

### 用户输入
帮我润色成适合生图的场景参考图提示词，风格统一成写实电影感：
“雨夜城市街道，有霓虹灯，路上很湿。”

### 预期输出要点
- 输出两条场景相关提示词：主视图提示词 + 四宫格整合图提示词
- 四宫格整合图是一张图，不是按四个方向拆成四张
- 主视图要先固定室外都市街景、夜晚氛围和湿润反光路面
- 四宫格整合图要写明“基于已生成的场景主视图继续生成”
- 不要加入未提及的人物

## 示例 3：把首尾帧粗描述改成更可用的提示词

### 用户输入
下面是一个镜头的首尾帧，请帮我改成更适合生图的提示词，统一成电影分镜感。
首帧：一个男人站在门口准备进去。
尾帧：他已经走进屋里，停在窗前。

### 预期输出要点
- 先给统一风格说明
- 分别输出首帧和尾帧
- 强调同一人物、同一服装逻辑、同一场景连续性
- 让首尾帧的动作关系自然衔接

## 示例 4：从分镜中拆出人物、场景和首帧

### 用户输入
下面是一段分镜，帮我拆出人物参考图、场景参考图和首帧提示词，统一成国风水墨：
镜头1：少年站在山门外，抬头望向山顶古寺。
镜头2：少年走进寺院长廊，风吹动他的衣摆。
镜头3：他在庭院中央停下，看着一棵巨大的古松。

### 预期输出逻辑
1. 识别重复人物：少年
2. 识别重复场景：山寺外景、寺院长廊、寺院庭院
3. 首帧按镜头生成
4. 不输出尾帧，因为用户没要求首尾帧模式

## 示例 5：只要提示词，不要解释

### 用户输入
只要提示词，不要解释。帮我把下面这段话拆成一个人物参考图和一个首帧提示词，统一成二次元主视觉：
“白发青年剑客站在雪地里，手扶长剑，抬头看向远处。”

### 预期输出要点
- 不输出分析
- 不输出额外说明
- 如果用户只是要单个人物锚点，可以只输出主参考图提示词和首帧提示词
- 不要擅自补成四套独立视角提示词

## 示例 6：用户已有风格，不要乱改

### 用户输入
帮我润色，但不要改变我的风格。我想要数字概念艺术风格。
“废墟里的机器人女孩，坐在断墙上，看着天上的飞船。”

### 预期输出要点
- 保留数字概念艺术
- 不擅自改成写实或二次元
- 补强主体、环境、构图、光线和一致性约束

## 常见触发语句

- 帮我把这个人物提示词润色成适合做三视图参考图的版本
- 帮我统一成水彩童书风格
- 下面是一段分镜，帮我拆成人物参考图、场景参考图和首帧提示词
- 下面这几个镜头需要首尾帧模式，请拆出来
- 我已经有一个粗糙提示词，请你帮我 polish 成更适合生图的版本
