# 声音设计参考手册

本文档为场景氛围设计提供声音层面的参考数据和标准用语。即使视频平台不支持音频，声音描述也能帮助完整理解场景的氛围维度。

---

## 环境音词汇表

按场景类型分类，提供该类场景中常见的环境音元素。

### 室内-古代

| 环境音元素 | 描述 | 适用场景 |
|-----------|------|----------|
| 木结构吱嘎声 | 老旧木质建筑随温度/风力轻微形变的声响 | 古宅、客栈、阁楼 |
| 烛火噼啪声 | 蜡烛灯芯燃烧的细微爆裂声 | 书房、密室、祠堂 |
| 翻书/翻纸声 | 纸张翻动的沙沙声 | 书房、藏经阁 |
| 木地板脚步声 | 踩在木板上的咚咚或嘎吱声 | 各类古代室内 |
| 远处钟声 | 寺院或城楼报时的悠远钟响 | 临近寺院/城楼的室内 |
| 风吹帘幕声 | 布帘被风吹动的轻柔拍打声 | 有窗户/门帘的房间 |
| 香炉细烟声 | 几乎无声，但暗示空气中有缭绕香烟 | 祠堂、修行室 |
| 研墨声 | 墨块在砚台上缓慢研磨的声音 | 书房 |
| 茶水倒注声 | 热水倒入茶杯的细流声 | 会客、密谈场景 |

## 情绪音效映射

| 情绪 | 音效元素 | 描述与用法 |
|------|---------|-----------|
| 紧张 | 心跳加速、呼吸急促、低音弦乐持续音(drone) | 心跳从60bpm渐进到120bpm暗示压力攀升；低频drone营造不安底色 |
| 平静 | 轻微风声、远处水流、偶尔鸟鸣 | 自然白噪音铺底，间歇点缀鸟鸣，营造安宁感 |
| 悲伤 | 雨滴、空旷回声、钢琴单音 | 雨声做底，偶尔一个钢琴单音如叹息般响起 |
| 喜悦 | 笑声远传、轻快背景音、鸟鸣频繁 | 明亮音色点缀，鸟鸣活跃，空间感开阔 |
| 恐惧 | 突然安静后的尖锐声、心跳、低频共振 | 先抽空所有环境音制造真空感，再突然插入尖锐刺耳声 |
| 惊讶 | 倒吸气声、环境突然安静、高频刺耳音 | 所有声音骤停半秒，随后高频音刺入 |
| 愤怒 | 拳头捶击、呼吸粗重、低音轰鸣 | 低频力量感加重，呼吸变粗，打击类声音增多 |
| 期待 | 渐强的背景音、心跳平稳加速、弦乐上行 | 音量和音高缓慢递进，制造"即将发生什么"的感觉 |
| 孤独 | 空旷回声、单一脚步声、远处模糊声响 | 大量混响暗示空间巨大而空旷，只有自身声音 |
| 释然 | 深呼吸、环境音逐渐归来、弦乐解决和弦 | 从紧张的憋气状态到长长呼气，环境音重新填满空间 |
| 震撼/敬畏 | 低频轰鸣、空灵合唱、风声 | 超越人类尺度的声音：巨大存在的低频振动+天籁般合唱 |

## 配乐情绪速查

| 情绪方向 | 推荐器乐/音色 | 速度 | 调性倾向 | 提示词描述 |
|----------|---------------|------|----------|-----------|
| 温馨治愈 | 原声吉他/钢琴/尤克里里 | 中速(80-100bpm) | 大调 | 「温暖原声吉他伴奏，节奏舒缓，旋律明亮」 |
| 紧张悬疑 | 弦乐震音/钢琴低音区/电子脉冲 | 中慢到中速(60-100bpm) | 不协和音程/半音进行 | 「弦乐震音持续，不协和音程制造不安」 |
| 史诗壮阔 | 管弦乐全奏/打击乐/合唱 | 中速到快速(90-140bpm) | 大调/教会调式 | 「管弦乐全奏，打击乐轰鸣，合唱层叠」 |
| 孤独忧伤 | 独奏大提琴/箫/口琴/钢琴 | 慢速(50-70bpm) | 小调 | 「大提琴独奏低吟，缓慢忧伤，小调旋律」 |
| 轻松幽默 | 拨弦/木管(单簧管/长笛)/口哨 | 中快(100-130bpm) | 大调 | 「拨弦跳跃轻快，木管俏皮旋律」 |
| 神秘超自然 | 电子合成器pad/空灵人声/反向音效 | 无固定节拍/缓慢 | 不确定/悬浮 | 「电子pad悬浮铺底，空灵人声飘渺」 |
| 战斗激烈 | 快速打击乐/铜管/电吉他失真/太鼓 | 快速(140-180bpm) | 小调/弗里几亚调式 | 「太鼓密集敲击，铜管嘶吼，节奏激烈」 |
| 浪漫柔情 | 弦乐四重奏/钢琴/竖琴 | 中慢(60-80bpm) | 大调/和声小调 | 「弦乐柔美缠绵，钢琴伴奏温柔」 |
| 庄严肃穆 | 管风琴/铜管合奏/低音弦乐 | 慢速(40-60bpm) | 小调/多利亚调式 | 「管风琴低沉庄严，铜管缓慢沉重」 |
| 空灵超脱 | 颂钵/古琴/环境电子/风铃 | 无固定节拍/极慢 | 五声音阶/无调性 | 「古琴泛音空灵，颂钵余音绵长，超然物外」 |
| 压迫窒息 | 低音drone/反复敲击/工业噪音 | 慢速但有压迫的脉冲(50-70bpm) | 无调/不协和 | 「低频drone持续压迫，金属敲击如倒计时」 |

## 声音过渡技巧

在场景切换时，声音的过渡方式可以强化叙事效果：

| 过渡方式 | 描述 | 适用场景 |
|----------|------|----------|
| 交叉淡化 | 前一场景声音渐弱，后一场景声音渐强，中间有重叠 | 平滑的时间/空间转换 |
| 硬切 | 声音突然完全切换，无过渡 | 突然的场景变化、惊醒、打断 |
| 声音桥接 | 下一场景的声音提前在当前场景出现（如先听到战斗声再切到战场） | 预示即将发生的事件 |
| 声音匹配切 | 前一场景结束的声音与后一场景开始的声音相似（如关门声→雷声） | 创意转场，暗示关联 |
| 静默过渡 | 所有声音淡出到完全安静，停顿后进入新场景 | 重大转折前的停顿、死亡、时间跳跃 |
| 回声消散 | 最后一个声音（如一句话/一声喊叫）以回声方式逐渐消散 | 进入回忆、意识模糊、坠落 |
