# 即梦 Seedance 2.0 分镜提示词生成器

## 概述

将用户输入的任意文字解析为一个或多个即梦 Seedance 2.0 视频分镜提示词，每条提示词可直接复制粘贴到 Seedance 2.0 的视频生成界面。

## 工作流程

### 第一步：分析内容

读取用户输入，判断：

1. **情节复杂度** → 决定分镜数量（每个分镜建议对应 4-15 秒视频）
2. **场景与主体** → 提取关键人物、场景、动作、情绪
3. **叙事节奏** → 确定时间节点分配

**分镜数量参考：**

| 内容类型 | 建议分镜数 |
|----------|-----------|
| 单一场景 / 简单动作 | 1 个 |
| 2-3 个场景转换 | 2-3 个 |
| 完整短片 | 4-6 个 |
| 复杂叙事 | 7-或更多个 |


### 第二步：构建每条提示词

每条提示词应包含（按优先级排列）：

1. **运镜方式**（必填）：明确镜头运动与视角
2. **主体描述**：人物特征、服装、表情
3. **场景 / 环境**：地点、光线、氛围
4. **动作 / 情节**：具体发生的事件；复杂动作用时间节点描述（`0-3秒: ... / 3-6秒: ...`）
5. **风格与画质**：写实 / 动漫 / 水墨等
6. **音效 / 音乐**：如有音画要求

**常用运镜词汇：**
固定镜头 · 推镜头 · 拉镜头 · 摇镜头 · 跟随镜头 · 俯拍 · 仰拍 · 低角度 · 一镜到底 · 第一人称主观视角 · 希区柯克变焦 · 环绕镜头 · 鸟瞰俯视

### 第三步：输出格式

以清晰格式输出每个分镜：

```
---
【分镜 1 / N】建议时长：X 秒

[完整提示词，可直接复制粘贴]
---
```

若用户打算上传参考素材，在提示词中用 `@图片X`、`@视频X`、`@音频X` 占位，并在最后附注使用说明。

## 剧情模式

当用户指定为"剧情模式"，或内容本身为连续剧情 / 剧本 / 多集叙事时，**自动启用**以下规则（在基础规则之上叠加）：

### 场景连续性原则

**核心要求**：相邻分镜之间的空间必须存在合理的物理或叙事连接，禁止无交代地跳切到完全不同的地点。

1. **场景动线规划**（前置步骤）：在写分镜之前，先列出本集所有场景及其空间关系，规划角色在场景间的移动路线。
2. **同一空间内展开**：尽量让连续的剧情在同一场景或相邻区域内发生。如果剧本中两个事件发生在不同地点，考虑能否合理调整为同一地点或相邻地点。
3. **过渡镜头**：必须转场时，用一个专门的过渡分镜交代空间移动（角色行走、镜头摇移到新地点、时间流逝蒙太奇等）。

**示例**：
- ✅ 练剑场 → 练剑场旁的镇妖柱（同一区域内转向）
- ✅ 室内 → 角色推门走出 → 庭院（过渡镜头）
- ❌ 练剑场 → 突然切到另一个庭院（无交代跳切）

### 角色台词与语音

剧情模式下，角色**必须有台词**。每个分镜的提示词应包含角色对白和/或旁白。

**台词写法**：
1. **角色对白**：在动作描述中嵌入，用引号标注台词内容，配合表情和肢体动作描写。格式示例：`苏小月瞪大眼睛，脱口而出："什么？！惹怒师兄？他会杀了我的！"`
2. **旁白 / 内心独白**：用于交代背景、衔接时间线、表达角色心理。在提示词中以 `旁白：` 或 `内心独白：` 标注。格式示例：`旁白（女声）："在青云派，有一个人人皆知的废柴弟子——苏小月。"`
3. **字幕叠加**：系统界面文字、技能名称等信息，用 `画面叠加字幕："xxx"` 标注。

**语音参考**：
- 如用户提供了角色语音素材，用 `@角色名语音` 引用以保持音色一致。
- 如用户提供了旁白语音素材，用 `@旁白语音` 引用。
- 语音素材通过「全能参考」入口与图片素材一同上传。

### 叙事节奏（参考结构）

| 阶段 | 时长占比 | 作用 |
|------|---------|------|
| 开场 | 前 10-15% | 建立镜头 + 旁白引入世界观/角色 |
| 铺垫 | 15-35% | 角色出场、情境建立、任务引入 |
| 发展 | 35-65% | 核心事件推进，角色互动与冲突 |
| 高潮 | 65-85% | 戏剧冲突爆发，视觉冲击最强 |
| 收尾 | 85-100% | 反转 + 情感落点 + 下集钩子 |

### 分镜数量（剧情模式）

剧情模式不受基础表格限制。根据剧集时长灵活调整：

| 每集时长 | 建议分镜数 |
|----------|-----------|
| 60 秒 | 7-10 个 |
| 90 秒 | 10-13 个 |
| 120 秒 | 12-16 个 |
| 150 秒 | 15-20 个 |
| 180 秒+ | 18 个或更多 |

## 参考素材审计

当用户提供了角色/道具/场景的参考图清单时，在写分镜提示词**之前**，必须执行以下审计流程：

### 第一步：逐分镜扫描

列出每个分镜中所有出场的视觉元素（角色、道具、场景、生物等），标注每个元素出现的分镜编号。

### 第二步：交叉比对

将扫描结果与用户提供的参考图清单逐一比对，找出以下两类问题：

**问题 A — 素材缺口**：某个视觉元素在 **2 个或以上分镜** 中出现，但没有对应的参考锚定图。
- 在没有参考图的情况下，AI 视频生成工具每次会随机生成该元素的外观，导致跨分镜不一致。
- **必须标记为缺口**，并为该元素生成补充参考图的提示词（遵循原剧本的画风前缀和格式规范）。

**问题 B — 素材状态不匹配**：某个参考图只覆盖了该元素的一种视觉状态，但分镜中需要该元素的不同状态（如完好 vs 碎裂、干净 vs 污染、日常 vs 觉醒）。
- **必须在分镜脚本中说明**：哪些分镜上传该参考图，哪些分镜用纯文字描述另一状态。

### 第三步：输出审计报告

在分镜脚本中插入「参考素材审计」章节，包含：

1. 原剧本提供的素材表
2. 发现的缺口列表（含严重程度：严重/轻微）
3. 现有素材的适用性问题
4. 补充素材的提示词（可直接用于生成锚定图）

## 注意事项

- 每条提示词对应 **4-15 秒**视频时长
- Seedance 2.0 **不支持上传写实真人脸部图像**，如涉及真人请提示风格化处理
- 纯文字生成可直接使用；包含参考素材（图 + 视频 + 音频）需通过**全能参考**入口
- 仅首帧图 + 文字描述可用**首尾帧**入口
- 多个参考素材时用 `@素材名` 明确指定用途

**同时将结果保存为 Markdown 文件：**

- 文件名：`{主题关键词}-Seedance分镜脚本.md`（如无明确主题，使用 `Seedance分镜脚本.md`）
- 保存位置：当前工作目录
- 文件内容包含：标题、生成时间戳、用户原始输入摘要、所有分镜提示词
