## 1. 镜头语言词汇

### 镜头运动

| 运镜类型 | 写法示例 |
|----------|----------|
| 固定镜头 | `固定镜头，人物从左入画` |
| 推镜 | `镜头缓慢向前推进，特写人物面部` |
| 拉镜 | `镜头拉远，露出全景` |
| 摇镜 | `快速摇镜头，转向对面特写` |
| 跟拍 | `镜头跟随人物移动，侧面跟拍` |
| 升降 | `镜头从低处缓缓上升，俯瞰全景` |
| 环绕 | `镜头环绕人物一圈，展示全貌` |
| 一镜到底 | `全程不要切镜头，一镜到底` |

### 视角

- 第一人称主观视角
- 俯拍（从上往下）
- 仰拍 / 低角度仰拍（英雄感）
- 鸟瞰俯视
- 平视：近景 / 中景 / 全景 / 远景

### 特殊手法

- **希区柯克变焦**：镜头推进同时拉焦，制造心理紧张感
- **延时摄影**：时间流逝、云朵移动、植物生长
- **慢动作**：突出动作细节
- **鱼眼镜头**：夸张的广角透视变形
- **跟镜**：机械臂多角度跟随人物视线

## 2. 时间节点写法

当一条提示词包含多个动作或场景时，用时间节点分段：

```
0-3秒：[场景/动作描述]
3-6秒：[场景/动作描述]
6-10秒：[场景/动作描述]
10-15秒：[结尾字幕/品牌收尾等]
```

**示例（产品广告）：**

```
0-2秒：快速四格闪切，红、粉、紫、豹纹四款蝴蝶结依次定格，特写缎面光泽与品牌字样。
3-6秒：特写磁吸扣"咔嗒"吸合，再轻轻一拉分开，展示丝滑质感与便捷性。
7-12秒：快速切换佩戴场景：酒红款别在大衣领口，粉色款绑在马尾，紫色款系在包带。
13-15秒：四款蝴蝶结并排陈列，品牌名渐显，旁白收尾。
```

**示例（氛围短片）：**

```
0-3秒：延时摄影，咖啡杯静置桌面，光影透过窗帘缓缓移动；
3-8秒：镜头缓缓推进至咖啡杯特写，热气升腾，背景虚化；
8-12秒：镜头拉远，露出整个温馨厨房空间；
12-15秒：画面渐暗，品牌logo在中央渐显。
```

## 3. 多模态参考语法

上传素材后，用 `@素材名` 在提示词中引用：

### 图片参考

```
@图片1 作为首帧           → 指定视频开始画面
@图片2 作为尾帧           → 指定视频结束画面
参考@图片1的场景风格      → 参考画面风格/环境
人物形象参考@图片1        → 参考人物长相/服装
```

### 视频参考

```
参考@视频1的运镜方式          → 复刻镜头语言
参考@视频1的动作和节奏        → 复刻动作
参考@视频1的特效风格          → 复刻特效/转场
将@视频1延长5s               → 视频续写（生成时长也选5s）
将@视频1中的人物换成...       → 角色替换编辑
```

### 音频参考

```
背景音乐参考@音频1            → 参考音乐风格/节奏
音色参考@视频1                → 参考声音特征
```

### 多素材组合示例

```
@图片1 作为首帧，参考@视频1的运镜效果，人物在@图片2的场景中奔跑，
背景音效参考@音频1的节奏。
```

```
参考@图片1的男人形象，他在@图片2的走廊中，完全参考@视频1的运镜效果，
镜头跟随主角奔跑，急停后怼脸拍摄主角正面。
```

## 4. 真实案例精选

### 人物日常动作（写实）

```
固定镜头，女孩在优雅地晒衣服，晒完接着在桶里拿出另一件，用力抖一抖衣服。
```

### 一镜到底追踪

```
一镜到底的追踪镜头，从街头跟随跑步者上楼梯、穿过走廊、进入屋顶，最终俯瞰城市。
```

### 谍战氛围

```
谍战片风格，@图片1 作为首帧，镜头正面跟拍穿着红风衣的女特工向前走，不断有路人
遮挡红衣女子，走到拐角处，固定镜头，红衣女子消失在拐角，一个戴面具的女孩在
拐角处躲着盯着她，面具女孩形象参考@图片3。全程不要切镜头，一镜到底。
```

### 商品/科技展示

```
第一人称视角，@图片1的平板电脑作为主体，参考@视频1运镜，推近到屏幕特写，
镜头旋转后平板反转展示全貌，屏幕中的数据流一直在变化，周围环境逐渐变成
科幻风格的数据空间。
```

### 视频延长

```
将@视频1延长6s。电吉他激昂音乐响起，视频中间出现"JUST DO IT"广告字体后
逐渐淡化，镜头上移到天花板，健硕男人拉着吊环，随后出现"DO SOME SPORT"
广告结束字体。
```

### 水墨特效

```
黑白水墨风格，@图片1的人物参考@视频1的特效和动作，上演一段水墨太极功夫。
```

### 情绪崩溃

```
@图片1的女子走到镜子前，看着镜子里的自己，沉思片刻突然崩溃大叫，抓镜子的
动作和崩溃大叫的情绪完全参考@视频1。
```

## 5. 常见场景模板

### 人物叙事类

```
[运镜]，[人物描述]在[场景/环境]中，[具体动作序列]，[情绪/表情变化]，
[音效/对话]。画面风格[写实/动漫/水墨等]。
```

### 产品广告类

```
0-Xs：[建立镜头，展示产品全貌，光线氛围]；
X-Ys：[特写展示核心卖点，材质/功能细节]；
Y-Zs：[使用场景展示，情绪氛围拉满]；
Z-15s：[品牌/广告语收尾，字幕渐显，旁白]。
```

### 情绪氛围类

```
[光影描述]，[镜头运动]，[主体]在[环境]中[动作]，[环境音/音乐]，
[风格]，整体氛围[温馨/紧张/梦幻/孤独等]。
```

### 一镜到底类

```
一镜到底，起始于[起点场景]，镜头[运动方式]，经过[过渡元素/场景]，
最终到达[终点场景]，全程不切镜，画面[风格]。
```

### 视频续写类

```
将@视频1延长Xs。[新增画面描述：人物/场景/动作/音效/字幕]。
```
（注：生成时长也须选为新增部分的时长）

### 音乐卡点类

```
[人物/主体]根据@视频1的音乐节奏进行卡点，参考@图片1@图片2...的画面内容，
在节拍处切镜，整体节奏感强，画面风格[梦幻/动感/etc.]。
```
