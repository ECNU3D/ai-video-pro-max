# 平台技术限制参考

## Seedance 2.0（即梦）

| 参数 | 规格 |
|------|------|
| 每镜时长 | 4-15秒 |
| 推荐时长 | 6-10秒效果最佳 |
| 横纵比 | 16:9, 9:16, 1:1 |
| 生成模式 | 文生视频 / 图生视频 / 全能参考 |

**备注**：
- 支持首尾帧参考，可精确控制镜头起止画面
- 运镜关键词丰富（固定/推/拉/摇/跟随/环绕/俯拍/仰拍/一镜到底等）
- 时长范围最宽，适配性最强

---

## Hailuo AI（海螺）

| 参数 | 规格 |
|------|------|
| 每镜时长 | 6秒 或 10秒（仅两档） |
| 推荐时长 | 6秒用于快节奏, 10秒用于叙事 |
| 横纵比 | 16:9, 9:16 |
| 生成模式 | 文生视频 / 图生视频 |

**备注**：
- 仅支持两个固定时长档位，无法自定义
- 时间序列描述（0-3秒: .../3-6秒: ...）可增大运镜幅度
- 镜头运动建议在5-6秒内完成

---

## Wanxiang 2.6（通义万相）

| 参数 | 规格 |
|------|------|
| 每镜时长 | 5秒 / 10秒 / 15秒（三档） |
| 推荐时长 | 10秒最稳定 |
| 横纵比 | 16:9, 9:16, 1:1 |
| 生成模式 | 单机叙事 / 多机位(智能多镜) / 参考生视频 |

**备注**：
- 多机位模式可一个提示词包含多个时间段镜头，适合连续叙事
- 最长15秒@1080P
- 支持@角色引用（最多2个角色），有利于角色一致性
- 三档时长选择，灵活度介于 Seedance 和 Hailuo 之间

## Vidu

| 参数 | 规格 |
|------|------|
| 每镜时长 | 4-8秒 |
| 推荐时长 | 4秒用于快切, 8秒用于叙事 |
| 横纵比 | 16:9, 9:16, 1:1 |
| 生成模式 | 文生视频 / 图生视频 |

**备注**：
- 4个以上主体需拆分为多个镜头
- 支持动态控制关键词：大动态 / 中等动态 / 小幅动态
- 最大8秒限制，长叙事镜头需拆分

## 平台适配规则

### 时长适配

当节奏规划中的镜头时长不在目标平台支持范围内时，按以下规则调整：

**Seedance 2.0**：
- 范围4-15秒，绝大多数规划时长可直接使用
- <4秒的极短镜头 → 调整为4秒，或与前/后镜头合并
- >15秒的超长镜头 → 拆分为两个镜头

**Hailuo AI**：
- 仅6秒和10秒两档
- 4-5秒 → 归入6秒档
- 6-8秒 → 归入6秒档
- 9-12秒 → 归入10秒档
- 13-15秒 → 拆分为6秒+6秒，或调整叙事后归入10秒档

**Wanxiang 2.6**：
- 仅5秒、10秒、15秒三档
- 4-7秒 → 归入5秒档
- 8-12秒 → 归入10秒档
- 13-15秒 → 归入15秒档
- >15秒 → 拆分

**Vidu**：
- 范围4-8秒
- <4秒 → 调整为4秒
- 9-10秒 → 拆分为两个4-5秒镜头
- 11-15秒 → 拆分为两个6-8秒镜头

### 拆分原则

当镜头需要拆分时，遵循以下原则：

1. **在动作间隙处拆分** — 避免在动作中途切断
2. **保持叙事连贯** — 拆分后的镜头在视觉上应能自然衔接
3. **各镜头独立成立** — 拆分后每个镜头仍需有独立的叙事功能
4. **景别/运镜可变化** — 拆分是引入景别变化的好机会（如一个MS拆为CU+FS）

### 总时长校验

适配完成后，重新累加所有镜头时长，确保：
- 与目标总时长偏差不超过 ±5%
- 若偏差过大，微调个别镜头时长（优先调整呼吸段/过渡段）
