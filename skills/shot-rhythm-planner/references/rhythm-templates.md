# 节奏模板参考库

## 通用节奏原则

### 张弛交替

每 2-3 个紧凑镜头（短时长/快运镜/近景别）后，必须安排 1 个呼吸镜头（较长时长/固定运镜/中远景）。连续快切不应超过 5 个镜头，否则观众会产生视觉疲劳。

### 渐进加速

开场慢 → 发展中速 → 高潮快 → 收尾减速。镜头时长整体呈递减趋势，在高潮段达到最短，收尾段略微回升。

### 呼吸空间

每 5-7 个镜头中至少安排 1 个静态/固定镜头。固定镜头的功能是让观众"消化"前面的信息，也为下一段蓄力。

### 对比法则

长镜头后接短镜头，冲击感更强；短镜头后接长镜头，沉浸感更深。刻意使用时长对比可以制造戏剧性节奏转折。

## 类型节奏模板

### 动作/冒险

| 参数 | 值 |
|------|------|
| 整体节奏 | 快速 |

| 高潮段时长 | 4-5秒，连续3-5个快切 |
| 景别偏好 | CU/MS为主(60%), ECU用于关键瞬间(10%), FS/LS用于动作场面(30%) |

### 悬疑/恐怖

| 参数 | 值 |
|------|------|
| 整体节奏 | 中慢 |
| 平均镜头时长 | 8-12秒 |
| 高潮段时长 | 突然加速(4-6秒) 或 极慢(12-15秒单镜长时间) |
| 景别偏好 | MS/CU为主(70%), ECU用于恐惧表情(15%), LS用于孤独感(15%) |
| 运镜分布 | 固定(35%重要!), 缓推(25%), 跟随(15%), 特殊(25%) |

**节奏曲线参考**：
```
▁▁▁▃▁▁▁▅▁▁▇█▁▁
```
特征：大量低强度镜头中穿插突然的爆发点。长时间的固定镜头营造不安感，突然快切制造惊吓。悬疑类型的核心节奏策略是"蓄力-释放"，蓄力时间越长，释放时冲击越大。

## 镜头时长参考

| 时长 | 分类 | 适用场景 |
|------|------|---------|
| 4-5秒 | 极短 | 快切/闪回/动作瞬间/惊吓点 |
| 6-8秒 | 短 | 动作/反应/快节奏叙事/喜剧笑点 |
| 8-10秒 | 标准 | 一般叙事/对话/情节推进 |
| 10-12秒 | 中长 | 情感表达/氛围营造/重要对话 |
| 12-15秒 | 长 | 场景建立/沉浸体验/关键情感时刻/世界观展示 |

**选择原则**：
- 信息密度高（动作多/对话快）→ 用较短时长
- 情感密度高（沉默/凝视/回忆）→ 用较长时长
- 叙事转折点 → 用时长对比（前长后短或前短后长）
