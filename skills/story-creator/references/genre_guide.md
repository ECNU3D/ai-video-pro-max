# 类型特化创作指南

## 爱情
- **叙事重点**：情感发展的细腻层次
- **核心公式**：相遇 → 误会/阻碍 → 感情升温 → 危机 → 和解
- **镜头偏好**：大量中近景和特写捕捉微表情，暖色调，柔光
- **角色建议**：性格互补的主角对，制造冲突的第三方
- **时长建议**：每集可稍长，留足情感铺垫空间

## 动作
- **叙事重点**：紧张的冲突和动作场面
- **核心公式**：危机出现 → 英雄行动 → 升级对抗 → 绝境 → 逆转胜利
- **镜头偏好**：快节奏剪辑，跟踪镜头，手持晃动增加临场感
- **角色建议**：目标明确的主角，强大的反派，可靠的搭档
- **时长建议**：镜头短促，高密度分镜

## 科幻
- **叙事重点**：世界观设定和技术元素融入剧情
- **核心公式**：新世界展示 → 主角目标 → 技术/道德困境 → 抉择 → 新秩序
- **镜头偏好**：大远景建立未来场景，特写展示科技细节
- **角色建议**：有探索精神的主角，代表不同立场的配角
- **风格参考**：赛博朋克、太空歌剧、近未来现实主义

## 奇幻
- **叙事重点**：奇幻世界的冒险和成长
- **核心公式**：召唤/使命 → 踏上旅途 → 考验 → 蜕变 → 归来
- **镜头偏好**：壮丽的远景展示奇幻世界，魔法特效的特写
- **角色建议**：成长型主角，智者导师，可爱伙伴
- **风格参考**：东方仙侠、西方奇幻、都市异能

## 喜剧
- **叙事重点**：制造笑点和误会
- **核心公式**：日常打破 → 荒诞升级 → 误会叠加 → 真相揭示 → 温馨收场
- **镜头偏好**：中景为主捕捉肢体喜剧，反应镜头（特写）
- **角色建议**：性格夸张鲜明的角色组合，制造化学反应
- **时长建议**：节奏紧凑，笑点密集

## 剧情
- **叙事重点**：深刻的人物内心世界和人生命题
- **核心公式**：平静日常 → 转折事件 → 内心挣扎 → 领悟/抉择 → 新的平衡
- **镜头偏好**：沉稳的固定镜头，大量特写展示内心世界
- **角色建议**：复杂立体的角色，灰色地带的道德选择
- **风格参考**：写实、文艺、生活流

## 恐怖
- **叙事重点**：恐惧感的递进和悬念营造
- **核心公式**：异常征兆 → 调查/深入 → 真相逼近 → 高潮恐惧 → 余韵
- **镜头偏好**：暗调画面，突然的特写，主观镜头增加代入感
- **角色建议**：普通人卷入非常事件，神秘的配角
- **时长建议**：节奏有张有弛，安静段落衬托恐怖高潮

## 悬疑
- **叙事重点**：层层设置悬念和线索
- **核心公式**：谜题出现 → 线索收集 → 误导/反转 → 真相渐近 → 揭晓
- **镜头偏好**：大量特写展示线索和表情，主观镜头，过肩镜头暗示监视
- **角色建议**：有洞察力的主角，各怀心思的嫌疑人
- **风格参考**：推理、犯罪、心理悬疑

## 纪录
- **叙事重点**：真实感和信息传递
- **核心公式**：引入主题 → 背景铺垫 → 深入探索 → 转折/发现 → 总结反思
- **镜头偏好**：大远景和远景为主，稳定的跟踪镜头
- **角色建议**：真实或基于真实的人物
- **风格参考**：人物纪录、自然纪录、社会观察

## 动画
- **叙事重点**：视觉想象力和情感表达
- **核心公式**：灵活，可融合任何类型的叙事结构
- **镜头偏好**：夸张的运镜和视角，丰富的视觉表现
- **角色建议**：造型鲜明、辨识度高的角色
- **风格参考**：日系动画、国风动画、欧美卡通、实验动画
