# 分镜审片系统

## 概述

对已完成的分镜脚本进行专业级质量审查，从8个维度评分并输出结构化审片报告和优先级修改清单。本技能是分镜创作流程的质量关卡，审查对象为 seedance/hailuo/wanxiang/vidu 等分镜技能的输出产物。

## 触发条件

- 用户已有完成的分镜 Markdown 文件，希望进行质量审查
- 用户提到"审查"、"审片"、"分镜审查"、"质量检查"、"review"

## 输入

1. **必须**: 已完成的分镜 Markdown 文件（seedance/hailuo/wanxiang/vidu 分镜技能的输出）
2. **可选**: 视觉设计文档（VDD），用于色彩连续性审查

## 参考资料

审查前必须加载以下参考文件：

- `references/review-checklist.md` — 8维度详细审查标准
- `references/shot-audit-rules.md` — 景别/运镜识别规则与扣分规则

## 工作流程

### 第一步：解析分镜文件

逐条提取每个镜头的元数据：

| 字段 | 说明 |
|------|------|
| 分镜编号 | Shot #1, #2, ... |
| 时长 | 秒数 |
| 场景 | 所在场景名称 |
| 运镜方式 | 从提示词开头提取 |
| 景别 | 从提示词中识别 |
| 提示词全文 | 完整 prompt 文本 |
| 风格尾缀 | 提示词末尾的风格/画质描述 |

如果用户同时提供了 VDD，也解析 VDD 中的色彩地图、角色色彩身份、色彩叙事弧线。

### 第二步：8维度分析

按照 `references/review-checklist.md` 中的标准，逐维度分析：

1. **景别分布** — 统计各景别出现次数与占比，对照理想分布
2. **运镜多样性** — 统计运镜类型分布，检查叙事匹配度
3. **色彩连续性** — 对照 VDD 检查色彩一致性（无 VDD 时检查风格尾缀同质化）
4. **构图意图** — 检查每个镜头是否有空间安排指导（前景/中景/背景、人物位置、光影方向）
5. **节奏分析** — 检查时长分布的变化性，高潮段是否加速
6. **视觉连续性** — 检查同场景光线一致性、角色外观一致性、时间连贯性
7. **提示词质量** — 检查风格尾缀同质化、光线描述、纵深层次、质感/粒子/氛围
8. **叙事完整性** — 检查叙事弧线覆盖度（开场→铺垫→发展→高潮→收尾）

### 第三步：评分

每个维度满分100分，根据 `references/shot-audit-rules.md` 中的扣分规则逐项扣减。

**加权总分计算：**

| 维度 | 权重 |
|------|------|
| 提示词质量 | 20% |
| 节奏分析 | 15% |
| 景别分布 | 15% |
| 运镜多样性 | 12% |
| 构图意图 | 12% |
| 色彩连续性 | 10% |
| 视觉连续性 | 10% |
| 叙事完整性 | 6% |

### 第四步：生成修改清单

将所有扣分项按优先级排序（扣分多的优先），生成具体修改建议。每条建议应包含：

- 涉及的分镜编号
- 具体问题描述
- **直接给出修改后的提示词文本**（而非抽象建议）

将审片报告保存为 Markdown 文件：`{标题}-审片报告.md`

### 第七步：询问自动修改

报告输出后，询问用户：

> 是否需要我根据修改清单自动修改分镜脚本？我会按优先级逐条修改并标注改动。

如用户同意，按优先级从高到低逐条修改原分镜文件，并将修改后的版本保存为 `{标题}-分镜脚本(已修订).md`。

## 核心原则

1. **质量关卡** — 诚实但有建设性，指出问题的同时给出具体解法
2. **可操作性** — 所有建议都必须是可直接执行的，给出修改后的提示词而非抽象理论
3. **三大常见问题**（重点检查）：
   - **#1 风格尾缀同质化**: 所有镜头使用完全相同的风格/画质尾缀，这是最严重也最常见的问题
   - **#2 时长均一化**: 所有镜头都是相同时长（如全部10秒），缺乏节奏变化
   - **#3 景别单调**: 过多中景镜头，缺少极端景别（ECU/LS）的视觉冲击

## 评级标准

| 等级 | 分数范围 | 含义 |
|------|---------|------|
| A+   | 95-100  | 专业级，几乎无需修改 |
| A    | 90-94   | 优秀，仅需微调 |
| B+   | 85-89   | 良好，有提升空间 |
| B    | 80-84   | 合格，建议修改 |
| C+   | 75-79   | 及格，需要修改 |
| C    | 70-74   | 勉强及格，多处需改 |
| D    | <70     | 不合格，建议重写 |
