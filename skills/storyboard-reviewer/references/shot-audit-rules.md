# 分镜审计规则 — 识别映射与扣分标准

## 1. 景别识别关键词映射

从提示词中匹配以下关键词，确定镜头景别：

| 关键词 | 景别 |
|--------|------|
| 大特写、极近、面部特写、眼部特写、手部特写、嘴唇特写、瞳孔 | ECU（大特写） |
| 特写、近景、头肩、面部、胸部以上、肩部以上 | CU（特写/近景） |
| 中景、半身、腰部以上、膝盖以上、上半身 | MS（中景） |
| 全景、全身、人物全貌、站立全身、完整身形 | FS（全景） |
| 远景、广角、宽景、航拍、鸟瞰、俯瞰全景、天际线、全貌 | LS（远景） |

**匹配优先级**: ECU > CU > MS > FS > LS（从具体到宽泛优先匹配）

**无法识别时**: 如果提示词中无明确景别关键词，根据描述内容推断：
- 仅描述面部/手部细节 → CU
- 描述人物动作+部分环境 → MS
- 描述人物全身+环境 → FS
- 描述大场景/建筑/风景 → LS

## 2. 运镜识别关键词映射

从提示词开头或运镜标注中匹配以下关键词：

| 关键词 | 运镜类型 |
|--------|---------|
| 固定、静止、固定镜头、static | 固定 |
| 推、推进、缓推、前推、dolly in、push in | 推 |
| 拉、后拉、拉远、拉开、dolly out、pull out | 拉 |
| 摇、平摇、左摇、右摇、环顾、pan | 摇 |
| 跟、跟随、跟拍、追踪、follow | 跟随 |
| 环绕、围绕、旋转、orbit、arc | 环绕 |
| 航拍、俯瞰、鸟瞰、上帝视角、drone、aerial | 航拍 |
| 升、起、升起、抬起、crane up、tilt up | 升 |
| 降、落、下降、crane down、tilt down | 降 |
| 手持、肩扛、handheld | 手持 |
| 变焦、急推急拉、zoom、dolly zoom | 变焦 |

**匹配优先级**: 优先匹配提示词开头的运镜描述，其次匹配正文中的运镜关键词。

**无法识别时**: 如果无明确运镜关键词，默认判定为"固定"。

## 3. 分数扣减规则

每个维度初始分100分，按以下规则扣减：

### 景别分布扣分

| 问题 | 扣分 | 触发条件 |
|------|------|---------|
| 中景占比过高 | -10 | MS 占比 > 50% |
| 缺少大特写 | -8 | ECU 出现次数 = 0 |
| 缺少远景 | -5 | LS 出现次数 = 0 |
| 连续相同景别 | -5/次 | 连续 3 个或以上镜头使用相同景别 |
| 单一景别占比过高 | -10 | 任一景别占比 > 50% |
| 景别种类过少 | -8 | 仅使用 2 种以下景别 |

### 运镜多样性扣分

| 问题 | 扣分 | 触发条件 |
|------|------|---------|
| 运镜种类过少 | -15 | 仅使用 2 种以下运镜 |
| 单一运镜占比过高 | -10 | 单一运镜类型占比 > 50% |
| 运镜与叙事不匹配 | -5/次 | 运镜选择与场景情绪明显不符 |
| 无特殊运镜 | -3 | 全程无环绕/航拍/手持/变焦 |

### 色彩连续性扣分

| 问题 | 扣分 | 触发条件 |
|------|------|---------|
| 全部相同风格尾缀 | -20 | 100% 镜头使用完全相同的风格/色彩尾缀 |
| 色彩与VDD不符 | -5/次 | 镜头色调与 VDD 色彩地图不匹配 |
| 同场景色温突变 | -5/次 | 同一场景内色温无理由跳变 |
| 角色色彩身份丢失 | -3/次 | 角色标志色在镜头中未体现 |

### 构图意图扣分

| 问题 | 扣分 | 触发条件 |
|------|------|---------|
| 全部无构图指导 | -25 | 所有镜头仅描述人物+动作，无空间安排 |
| 多数无构图指导 | -15 | 超过 50% 的镜头缺少构图指导 |
| 无纵深层次 | -10 | 全部镜头无前景/中景/背景分层 |
| 无光影方向 | -8 | 全部镜头无光影方向描述 |

### 节奏分析扣分

| 问题 | 扣分 | 触发条件 |
|------|------|---------|
| 所有镜头相同时长 | -20 | 全部镜头时长完全一致 |
| 时长变化极小 | -12 | 标准差 < 1秒 |
| 高潮段无加速 | -10 | 高潮/紧张段落与平静段落节奏相同 |
| 无呼吸空间 | -5 | 全程无 8-12秒的缓冲镜头 |
| 节奏完全平坦 | -8 | 无任何节奏波动 |

### 视觉连续性扣分

| 问题 | 扣分 | 触发条件 |
|------|------|---------|
| 角色描述不一致 | -8/次 | 同一角色在不同镜头中外观描述矛盾 |
| 同场景光线矛盾 | -5/次 | 同一场景内光线方向不一致 |
| 时间线断裂 | -5/次 | 时间逻辑矛盾（如黄昏后突然正午）无标注 |
| 无场景过渡 | -3/次 | 场景硬切无任何过渡设计 |

### 提示词质量扣分

| 问题 | 扣分 | 触发条件 |
|------|------|---------|
| 全部相同风格尾缀 | -25 | 100% 镜头使用完全相同的通用风格尾缀 |
| 全部无光线描述 | -15 | 所有镜头无任何光线方向/色温/强度描述 |
| 全部无纵深层次 | -10 | 所有镜头无前景/中景/背景描述 |
| 无质感/纹理描述 | -5 | 全部镜头无表面质感描述 |
| 无粒子/氛围描述 | -5 | 全部镜头无大气效果描述 |
| 提示词过短 | -3/次 | 单条提示词少于 30 字 |
| 提示词过于笼统 | -3/次 | 使用大量模糊/通用描述而非具体画面 |

### 叙事完整性扣分

| 问题 | 扣分 | 触发条件 |
|------|------|---------|
| 缺少高潮镜头 | -15 | 叙事弧线中无高潮段 |
| 缺少开场建立 | -10 | 无建立镜头/世界观展示 |
| 缺少收尾 | -8 | 叙事无结尾/悬而未决 |
| 关键情节遗漏 | -5/次 | 原始故事中的关键事件无对应镜头 |
| 角色无建立 | -5/次 | 主要角色突然出现无出场铺垫 |

## 4. 评级标准

根据加权总分确定等级：

| 等级 | 分数范围 | 含义 | 建议行动 |
|------|---------|------|---------|
| A+ | 95-100 | 专业级，几乎无需修改 | 可直接进入生产 |
| A  | 90-94  | 优秀，仅需微调 | 修改 P2 级建议后可生产 |
| B+ | 85-89  | 良好，有提升空间 | 建议修改 P1 级以上建议 |
| B  | 80-84  | 合格，建议修改 | 修改 P0-P1 级建议 |
| C+ | 75-79  | 及格，需要修改 | 必须修改 P0 级建议 |
| C  | 70-74  | 勉强及格，多处需改 | 大幅修改后重新审查 |
| D  | <70    | 不合格，建议重写 | 建议重新生成分镜脚本 |

---

## 5. 优先级定义

修改清单中的优先级含义：

| 优先级 | 含义 | 说明 |
|--------|------|------|
| P0 | 必须修改 | 严重影响成片质量的问题，如全部相同时长/尾缀 |
| P1 | 强烈建议修改 | 明显影响观感的问题，如景别单调/运镜单一 |
| P2 | 建议修改 | 可提升品质的问题，如缺少氛围描述/构图指导 |
| P3 | 可选修改 | 锦上添花的优化，如增加质感描述/声音描述 |
