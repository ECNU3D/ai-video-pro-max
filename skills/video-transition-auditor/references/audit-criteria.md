# 预检审查评分标准

## 维度 1：首帧-提示词一致性

### 检查项与扣分规则

| 检查项 | 一致(0) | 轻微偏差(-2~-3) | 明显不一致(-5~-8) | 严重冲突(-10+) |
|--------|---------|-----------------|-------------------|---------------|
| 主体身份 | 人物/物体完全匹配 | 细节差异(发色略偏/配饰缺失) | 人物特征明显不同 | 完全不同的人/物(一票否决) |
| 姿态动作 | 姿势与描述匹配 | 角度略偏但意图一致 | 姿势与描述不符 | 站/坐/躺等基本姿态矛盾 |
| 服装道具 | 穿着完全一致 | 颜色/纹理略有偏差 | 服装类型不同 | 完全不同的着装风格 |
| 构图机位 | 景别和角度匹配 | 景别接近但角度略偏 | 景别不同(提示词说特写但首帧是中景) | 完全不同的构图(仰拍vs俯拍) |
| 场景环境 | 场景完全匹配 | 小细节差异(家具位置略偏) | 场景氛围不同 | 完全不同的场景(室内vs室外) |
| 光线色温 | 光线方向和色温一致 | 色温略有偏差 | 光线方向不同(侧光vs逆光) | 昼夜矛盾 |
| 画风风格 | 风格完全一致 | 风格接近但渲染细节不同 | 风格有差异(半写实vs全写实) | 完全不同的画风(2D vs 3D) |

### 评分方法

- 满分：本维度对应的权重分值
- 从满分开始，按上表逐项扣减
- 最低 0 分

## 维度 2：尾帧-提示词一致性（仅首尾帧模式）

### 检查项

与维度 1 相同的检查项，但对比对象是尾帧与提示词的「目标状态」。

### 额外检查

| 检查项 | 说明 | 扣分 |
|--------|------|------|
| 目标状态体现 | 提示词描述的终态是否在尾帧中可见 | 未体现: -8 |
| 帧词矛盾 | 尾帧画面与提示词目标状态是否矛盾 | 矛盾: -15 (一票否决) |
| 变化可见性 | 从首帧到尾帧的变化是否与提示词一致 | 变化方向相反: -10 |

## 维度 3：首尾帧一致性（仅首尾帧模式）

### 检查项与扣分规则

| 检查项 | 一致(0) | 轻微偏差(-1~-2) | 明显不一致(-3~-5) | 严重问题 |
|--------|---------|-----------------|-------------------|---------|
| 角色身份 | 同一人物，面部一致 | 面部略有差异但可辨认 | 面部特征明显不同 | 不是同一个人(一票否决) |
| 服装连贯 | 完全一致 | 细微差异 | 服装变化但提示词未要求 | — |
| 场景连贯 | 同一场景 | 小细节变化 | 场景变化但提示词未要求切场 | 无关场景跳切 |
| 画风统一 | 完全一致的画风 | 色调略有偏差 | 画风明显不同 | 完全不同风格 |
| 变化合理性 | 变化在时长内自然可行 | 变化较大但有可能 | 变化量过大，可能导致中间过渡不自然 | 物理不可行(一票否决) |

### 变化量合理性评估

根据目标视频时长判断首尾帧差距是否合理：

| 时长 | 合理变化量 | 风险变化量 | 不可行变化量 |
|------|-----------|-----------|-------------|
| 4-6秒 | 表情微变/轻微运镜/小幅动作 | 明显姿态变化/中幅运镜 | 大幅位移/场景切换/复杂动作序列 |
| 6-10秒 | 明显表情变化/中幅运镜/起身坐下 | 全身位移/大幅运镜/多步动作 | 跨场景/复杂连续动作 |
| 10-15秒 | 全身位移/大幅运镜/多步连续动作 | 跨区域移动/复杂交互 | 完全不相关的两个画面 |

## 维度 4：迁移逻辑完整性

### 检查项与扣分规则

| 检查项 | 满分条件 | 扣分场景 |
|--------|---------|---------|
| 变化是否明确(-10) | 提示词清楚描述了要发生什么变化 | 未描述任何变化: -10 / 变化描述模糊: -5 |
| 变化是否可行(-8) | 描述的变化在物理/逻辑上合理 | 物理不可行: -8 / 可行但困难: -3 |
| 顺序是否清晰(-5) | 多个变化有明确先后顺序 | 多变化无顺序: -5 / 部分不清: -2 |
| 禁止项是否声明(-5) | 不该变化的部分已明确声明 | 完全未声明: -5 / 部分声明: -2 |
| 运镜匹配(-5) | 运镜与变化内容协调 | 运镜与内容矛盾: -5 / 无运镜指令: -3 |
| 时序节点(-5) | 有时间节点拆分(0-3秒/3-6秒等) | 无时间节点: -3 / 节点不合理: -5 |
| 首尾帧差距可达(-7) | 从首帧到尾帧的变化在时长内可达 | 差距过大: -7 / 略大: -3 |

### 常见迁移逻辑缺陷

| 缺陷类型 | 示例 | 风险等级 |
|---------|------|---------|
| 目标状态缺失 | 只描述了动作，没说最终要达到什么状态 | 高 |
| 变化方向矛盾 | 提示词说"镜头推进"但首尾帧显示拉远 | 高 |
| 时间线超载 | 4秒视频里塞了5个连续动作 | 高 |
| 隐含假设 | "她走到门口"但首帧离门很远，4秒内走不到 | 中 |
| 运镜-内容脱节 | 提示词说"固定镜头"但要求大幅位移 | 中 |
| 缺少禁止项 | 未声明"不换场景"，AI可能自由切换 | 低-中 |

## 维度 5：提示词质量

### 检查项与扣分规则

| 检查项 | 满分条件 | 扣分场景 |
|--------|---------|---------|
| 结构完整性(-8) | 包含运镜+主体+场景+动作+风格 | 缺少2项以上: -8 / 缺少1项: -3 |
| 时序节点(-5) | 有 0-Xs / X-Xs 的时间分段 | 无分段: -3 / 分段不合理: -5 |
| 运镜关键词(-5) | 使用目标平台支持的运镜词汇 | 关键词错误: -5 / 缺少运镜: -3 |
| 内部一致性(-8) | 提示词内部无矛盾 | 存在矛盾: -8 / 表述模糊: -3 |
| 平台适配(-5) | 长度和格式适合目标平台 | 过长/过短: -3 / 格式不匹配: -5 |
| 关键信息完整(-5) | 无遗漏关键描述 | 缺少光线描述: -2 / 缺少表情变化: -2 / 缺少动作细节: -2 |

### 各平台提示词规范速查

| 平台 | 推荐结构 | 常见问题 |
|------|---------|---------|
| Seedance | 运镜+@参考+主体描述+动作时序+风格 | 缺少@引用、时序节点不合理 |
| Hailuo | 主体+场景+动作+运镜+美学氛围 | 运镜时序>6秒、缺美学描述 |
| Wanxiang | 美学控制+景别+主体+场景+动作+运镜+风格 | 多机位格式错误、@角色引用缺失 |
| Vidu | 主体/场景—场景描述—环境—艺术风格 | 动态控制词缺失、主体过多 |

## 一票否决规则汇总

以下任一项出现，无论总分多高，直接判定「不通过」：

| 编号 | 条件 | 维度 |
|------|------|------|
| V1 | 首帧主体身份与提示词严重不匹配 | 维度1 |
| V2 | 尾帧与提示词目标状态严重矛盾 | 维度2 |
| V3 | 首尾帧之间角色身份不一致（非提示词要求） | 维度3 |
| V4 | 提示词既没描述变化也没描述目标状态 | 维度4 |
| V5 | 首尾帧差距在目标时长内物理不可行 | 维度3/4 |
| V6 | 提示词内部存在严重自相矛盾 | 维度5 |

## 置信度评估

| 置信度 | 条件 |
|--------|------|
| 高 | 提示词明确、首帧清晰、所有维度可确定判断 |
| 中 | 提示词部分模糊，或首帧某些细节不够清晰 |
| 低 | 提示词严重模糊，或首帧质量差/细节不可辨 |

当置信度为「低」时，在报告中明确指出哪些判断是不确定的，建议用户补充信息后重新检查。
