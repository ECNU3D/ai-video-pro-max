# Vidu 分镜提示词生成器

## 概述

将用户输入的剧情或剧本，解析为一个或多个 Vidu 视频分镜提示词，并将结果保存为 Markdown 文件。每条提示词可直接粘贴到 Vidu 的文生视频或图生视频界面。

## 工作流程

### 第一步：分析内容

读取用户输入，判断：

1. **情节复杂度** → 决定分镜数量（每个分镜建议对应 4-8 秒视频）
2. **场景与主体** → 提取关键人物、场景、动作、情绪
3. **叙事节奏** → 确定时间节点分配
4. **风格倾向** → 写实、动漫、3D渲染等

**分镜数量参考：**

| 内容类型 | 建议分镜数 |
|----------|-----------|
| 单一场景 / 简单动作 | 1 个 |
| 2-3 个场景转换 | 2-3 个 |
| 完整短片 / 复杂叙事 | 4-6 个 |

### 第二步：构建每条提示词

**Vidu 提示词基础架构：**
`主体/场景 — 场景描述 — 环境描述 — 艺术风格/媒介`

每条提示词应包含（按优先级排列）：

1. **主体描述**（必填）：人物特征、服装、表情，或场景主体
2. **场景/环境**：地点、时间、氛围
3. **主体动态**：具体的运动或变化动作
4. **镜头运动**：用镜头关键词指定运动方式
5. **艺术风格**：画面风格、色调、氛围词

**动态控制关键词：**
- 大动态：大动态 / 快速运动 / 超大动效
- 中动态：中等动态 / 一般动效
- 小动态：小幅动态 / 小动态

**常用运镜词汇：**

| 类型 | 词汇 |
|------|------|
| 基础运镜 | 推镜头 · 拉镜头 · 升镜头 · 降镜头 · 左移 · 右移 · 固定镜头 |
| 组合运镜 | 推+顺时针旋转 · 拉+逆时针旋转 · 降+推 · 升+拉 |
| 特殊手法 | 延时摄影 · 微距镜头 · 第一人称视角(FPV) · 航拍镜头 |
| 景别 | 远景 · 全景 · 中景 · 近景 · 特写 |
| 视角 | 低角度 · 高角度 · 平视 · 鸟瞰 · 越肩镜头 |

**氛围关键词：**
快乐→明亮色彩 · 悲伤→冷色调 · 宁静→柔和色调 · 紧张→阴暗光线 · 温馨→暖色调+柔和光线

**提示词调优技巧：**
- 避免模糊术语，使用口语化准确描述
- 避免主体物过多/过于复杂
- 氛围词可在提示词中多次重复强化
- 通过主体与背景的大小比例关系营造运动方向感
- 加入镜头控制后，人物动作自然度会显著提升

详细风格关键词和完整案例，请查阅：**[references/vidu-guide.md](references/vidu-guide.md)**

### 第三步：输出并保存 Markdown 文件

**屏幕输出格式：**

```
---
【分镜 1 / N】建议时长：X 秒

[完整提示词，可直接复制粘贴]
---
```

**同时将结果保存为 Markdown 文件：**

- 文件名：`{主题关键词}-Vidu分镜脚本.md`（如无明确主题，使用 `Vidu分镜脚本.md`）
- 保存位置：当前工作目录
- 文件内容包含：标题、生成时间戳、用户原始输入摘要、所有分镜提示词

**Markdown 文件结构：**

```markdown
# {主题}-Vidu分镜脚本

> 生成时间：{时间} | 分镜数：{N} | 平台：Vidu

## 原始输入

{用户输入的剧情/剧本摘要}

## 分镜提示词

### 分镜 1（建议时长：X 秒）

{完整提示词}

### 分镜 2（建议时长：X 秒）

{完整提示词}

---
*提示词格式适配：Vidu 文生视频 / 图生视频*
```

## 注意事项

- 每个分镜对应 **4-8 秒**视频时长，单个镜头运动不宜过于复杂
- 提示词越丰富准确，生成效果越好；氛围词可重复强化
- 图生视频时：图片作为首帧，可适当减少主体描述信息量
- 多主体场景（4个以上）建议拆分为多个分镜
- 如需使用参考主体，在提示词中用 `@主体名` 占位，并在备注说明
