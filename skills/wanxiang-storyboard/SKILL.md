# 通义万相 2.6 分镜提示词生成器

## 概述

将用户输入的剧情或剧本，解析为一个或多个通义万相 2.6 视频分镜提示词，并将结果保存为 Markdown 文件。

## 工作流程

### 第一步：分析内容

读取用户输入，判断：

1. **情节复杂度** → 决定分镜数量（每个分镜建议对应 5-15 秒视频）
2. **场景与主体** → 提取关键人物、场景、动作、情绪
3. **叙事节奏** → 确定时间节点分配
4. **生成模式** → 判断是否使用多镜头模式（复杂叙事）或单镜头模式（简单场景）

**分镜数量参考：**

| 内容类型 | 建议分镜数 |
|----------|-----------|
| 单一场景 / 简单动作 | 1 个 |
| 2-3 个场景转换 | 2-3 个 |
| 完整短片 / 复杂叙事 | 4-6 个 |

### 第二步：选择提示词公式

根据内容类型选择合适的公式：

- **单镜头叙事（进阶公式）**：主体描述 + 场景描述 + 运动描述 + 美学控制 + 风格化
- **多镜头公式**：总体描述 + `第N个镜头[时间戳]` + 分镜内容
- **含声音**：在进阶公式末尾追加声音描述（人声/音效/背景音乐）
- **参考角色**（万相 2.6）：`@主角` + 动作 + 台词 + 场景

### 第三步：构建每条提示词

每条提示词应包含（按优先级排列）：

1. **美学控制**（建议写在开头）：光源、光线、时间段、色调
2. **景别与构图**：特写 / 近景 / 中景 / 全景 + 构图方式
3. **主体描述**：人物特征、服装、表情、情绪
4. **场景 / 环境**：地点、背景、氛围
5. **运动 / 动作**：具体发生的事件，可用时间节点描述（`0-3秒: ... / 3-6秒: ...`）
6. **运镜方式**：固定镜头 / 推镜 / 拉镜 / 跟拍 / 环绕等
7. **风格化**：写实 / 动漫 / 水墨 / 赛博朋克等（如有需要）
8. **声音描述**：人声台词、音效、背景音乐（如有声音需求）

**多镜头格式示例：**
```
这个故事以第三人称视角，讲述了...（总体描述）

第1个镜头[0-3秒]...（分镜内容）

第2个镜头[4-6秒]硬切转场，...（分镜内容）

第3个镜头[7-10秒]硬切转场，...（分镜内容）
```

### 第四步：输出并保存 Markdown 文件

**屏幕输出格式：**

```
---
【分镜 1 / N】建议时长：X 秒

[完整提示词，可直接复制粘贴]
---
```

**同时将结果保存为 Markdown 文件：**

- 文件名：`{主题关键词}-万相分镜脚本.md`（如无明确主题，使用 `万相分镜脚本.md`）
- 保存位置：当前工作目录
- 文件内容包含：标题、生成时间戳、用户原始输入摘要、所有分镜提示词

**Markdown 文件结构：**

```
# {主题}-万相分镜脚本

> 生成时间：{时间} | 分镜数：{N} | 平台：通义万相 2.6

## 原始输入

{用户输入的剧情/剧本摘要}

## 分镜提示词

### 分镜 1（建议时长：X 秒）

{完整提示词}

### 分镜 2（建议时长：X 秒）

{完整提示词}

---
*提示词格式适配：通义万相 2.6 文生视频*
```

## 注意事项

- 每条提示词对应 **5，10，15 秒**三种视频时长（万相 2.6 最长支持 15 秒 1080P）
- **多镜头模式**：将完整多镜头描述作为一条提示词输入，万相会自动处理分镜衔接
- **单镜头模式**：每个分镜单独输入，分别生成后剪辑拼接
- 参考角色功能（`@主角`）适用于**万相 2.6 参考生视频**入口，需上传参考视频
- 若需要智能多镜效果，可开启万相界面的「智能多镜」功能配合简单提示词
