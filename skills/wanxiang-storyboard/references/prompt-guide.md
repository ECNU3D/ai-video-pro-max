## 1. 提示词公式总览

### 基础公式（适合新手）
```
主体 + 场景 + 运动
```

### 进阶公式（推荐）
```
主体（主体描述）+ 场景（场景描述）+ 运动（运动描述）+ 美学控制 + 风格化
```

### 图生视频公式
```
运动 + 运镜
```

### 声音公式（万相 2.5+）
```
主体 + 场景 + 运动 + 声音描述（人声/音效/背景音乐）
```

**人声格式：** `"角色说话的内容"` + 情绪 + 语调 + 语速 + 音色 + 口音

**音效格式：** 音源材质 + 行为 + 环境音

**背景音乐格式：** 背景音乐/配乐 + 风格

### 参考生视频公式（万相 2.6）
```
@主角 + 动作 + 台词 + 场景
```
*通过 `@` 引用参考视频中的角色，支持最多 2 个主角合拍*

### 多镜头公式（万相 2.6）
```
总体描述 + 第N个镜头[时间戳] + 分镜内容
```

## 2. 美学控制词汇

### 光源类型

| 光源 | 适用场景 |
|------|----------|
| 日光 | 户外自然光，温暖写实 |
| 人工光 | 室内灯光，台灯、顶灯 |
| 月光 | 夜晚室内外，神秘冷调 |
| 实用光 | 场景内部光源（蜡烛、手机屏幕） |
| 火光 | 篝火、壁炉、烛光，暖橙色调 |
| 荧光 | 走廊、办公室日光灯，冷白色调 |
| 阴天光 | 户外漫射光，柔和低对比 |
| 混合光 | 多种光源叠加，层次丰富 |
| 晴天光 | 直射阳光，高对比度 |

### 光线类型

| 光线 | 效果 |
|------|------|
| 柔光 | 柔和，减少阴影，温馨感 |
| 硬光 | 强烈阴影，戏剧感 |
| 顶光 | 从正上方照射 |
| 侧光 | 单侧照射，立体感强 |
| 背光 | 逆光，轮廓清晰，梦幻感 |
| 底光 | 从下方照射，恐怖或神秘感 |
| 边缘光 | 勾勒轮廓线，电影质感 |
| 剪影 | 高对比度剪影效果 |
| 低对比度 | 柔和过渡，复古感 |
| 高对比度 | 强烈明暗对比，戏剧感 |

### 时间段

白天 · 夜晚 · 黄昏 · 日落 · 黎明 · 日出

### 色调

暖色调 · 冷色调 · 低饱和度 · 高饱和度 · 混合色调

## 3. 景别与构图

### 景别（从近到远）

| 景别 | 说明 |
|------|------|
| 特写 | 面部或细节，情绪强调 |
| 近景 | 胸部以上，人物表情清晰 |
| 中近景 | 腰部以上 |
| 中景 | 膝盖以上，兼顾人物与环境 |

| 全景 | 完整展示人物与场景 |
| 广角 | 宽阔视野，强调空间关系 |

中心构图 · 左侧重构图 · 右侧重构图 · 对称构图 · 短边构图

### 拍摄角度

平拍 · 俯视角度 · 仰拍（低角度） · 过肩镜头 · 鸟瞰俯视

## 5. 声音描述

### 人声

```
角色说话时，用[情绪]的[语调]说道："[台词内容]"，语速[快/适中/慢]，声音[音色特征]，[口音]。
```

**情绪：** 激动、平静、恐慌、低沉、轻柔、急促
**音色：** 清亮、低沉、童音、沙哑、柔和
**口音：** 普通话、京腔、粤语、美式英文、英式英文

**唱歌格式：** `[演唱中文/英文歌曲]` 或 `用极快的语速演唱英文rap`

### 音效

```
[动作/物体] + [声音描述]
```

**常见音效：** 脚步声 · 敲门声 · 碰撞声 · 火焰燃烧声 · 键盘声 · 动物叫声 · 电子音效 · ASMR

### 环境音

```
背景音为[环境描述]，伴有[具体音效]。
```

**常见环境音：** 树叶沙沙声 · 鸟鸣 · 列车轰鸣 · 城市嗡嗡声 · 宇宙白噪音 · 室内安静

### 背景音乐

```
配有[风格]背景音乐 / 背景音乐是[描述]。
```

**音乐风格：** 温馨快乐 · 悬疑 · 8-bit像素 · 卡点音乐 · 轻音乐/钢琴 · 放克 · 交响 · 电子

## 7. 完整示例精选

### 多镜头叙事（万相 2.6）

```
这个故事以第三人称视角，讲述了一个关于放弃与重拾希望的短剧。

第1个镜头[0-3秒]一个男孩在操场的角落独自坐着，低头望着手中的信纸，随后轻轻叹气，眼神中透露出迷茫。

第2个镜头[4-6秒]硬切转场，固定机位，聚焦于男孩的眼睛，泪光闪烁，带着失落和无助。

第3个镜头[7-10秒]硬切转场，场景转至一间简朴的教室。一个女孩眼神温和而坚定，穿着朴素的衣着，面带温和而坚定的笑容，走到男孩的身边安慰他。
```

### 参考角色合拍（万相 2.6）

```
这是一个充满童趣的童话场景。@A 在草地上蹦跳着玩耍，@B 在旁边的一颗苹果树下弹奏钢琴，一颗苹果掉到了@B 的头上，@A 开心的指着@B 说："你要变成科学家了！"。
```
*其中A的参考视频是一只兔子，B的参考视频是一只狗*

### 单镜头人声对话

```
暖色调，日光，柔光，侧光，中景，中心构图，全景。红色背景的舞台铺着光滑的木质地板，两束聚光灯从上方斜射而下，照亮一对恋人。男人比女人略高，身穿剪裁合体的深灰色西装，面容清晰，眼神专注；女人身着酒红色长裙，发丝乌黑柔顺。两人深情对视。她轻启唇瓣，低声呢喃："这一刻，像梦一样。" 他凝视着她，回应道："但它是真的。"
```

### 含音效的写实场景

```
蒸汽朋克风格，黄昏，混合光，侧光，冷色调中透着橙红辉光，中全景，中心构图。镜头平缓推进，展现一座维多利亚时代城市中阴暗狭窄的铁轨小巷，青石路面反射着湿漉漉的微光，浓雾缓缓流动。一群复古造型的机器人列队穿行，关节处喷出细小蒸汽，脚步声，金属足部敲击地面发出"咔嗒"节奏声。背景深处，巨型齿轮状建筑拔地而起，顶部矗立无线电塔，持续发射出淡蓝色电弧，伴随低频电流嗡鸣声。
```

### 情绪氛围（慢节奏）

```
柔光，黄昏，侧光，低饱和度，冷色调，中心构图，中近景。一个娇小的女孩站在夜晚的街道旁，周围是渐暗的暮色。她有着棕色卷发，披肩自然垂落，脸颊泛红，泪水沿着脸庞缓缓滑落。女孩身穿浅米色针织外套和深蓝色短裙，双手轻轻握着衣角，神情失落而安静。背景是一条空旷的城市道路，远处街灯刚刚亮起，散发出柔和的黄色光晕，与天边残留的深蓝色形成对比。镜头聚焦于女孩的表情，营造出细腻而富有情绪的画面。
```

### 一镜到底动作场景

```
一镜到底的追踪镜头，从街头跟随主角奔跑上楼梯、穿过走廊、进入屋顶，最终俯瞰城市。写实风格，手持拍摄，剧烈晃动感，夜晚，人工光，霓虹灯照射，冷色调。
```
