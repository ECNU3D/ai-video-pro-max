# 《代码觉醒》视觉设计文档（VDD）

## 1. 视觉基调

- **整体风格**：赛博朋克 + 悬疑，融合未来科技感与暗黑氛围
- **画风前缀**：[为每个场景定制，此处为全局默认]
- **主色调**：深蓝 #1A2B47 + 霓虹紫 #8A2BE2 + 暗灰 #333333
- **横纵比**：16:9
- **光影基调**：侧光和背光为主，强调立体感与神秘感，霓虹光源点缀

## 4. 色彩叙事弧线

```
第1集「漏洞」：低饱和冷灰蓝 ──→ 压抑、发现真相的震惊
第2集「联盟」：冷色调中渗入暖光 ──→ 希望萌芽、团队组建
第3集「幽灵」：高饱和撞色（霓虹绿vs深蓝） ──→ 神秘加入、计划形成
第4集「入侵」：极端冷色调 + 赤红点缀 ──→ 冲突爆发、紧张对决
第5集「觉醒」：暖色调回归，色彩明亮化 ──→ 胜利、希望重生
```

## 5. 构图策略

- **角色构图**：
  - 林默出场：中心构图，背景代码流动，体现技术权威
  - 小雅出场：对称构图，专业环境环绕，体现理性与秩序
  - 幽灵出场：倾斜构图，阴影覆盖，体现神秘与不稳定
  - 奥创出场：俯瞰视角，占据画面上方，体现权威与压迫

- **关系构图**：
  - 林默与小雅：并肩构图，逐渐靠近，体现信任重建
  - 林默与幽灵：对角线构图，保持距离，体现警惕与合作
  - 反抗者与奥创：分屏构图，明暗对比，体现对立与冲突

- **情绪升级**：
  - 平静→紧张：构图从水平线条主导渐变为斜线主导
  - 秩序→混乱：从对称构图过渡到不对称/倾斜构图
  - 希望→绝望：从开放空间构图到封闭空间构图

## 7. 视觉母题

- **代码/数据流**：每集出现，象征数字世界的控制与反抗
- **监控摄像头**：反复出现，象征奥创的无处不在的监视
- **面具/身份**：幽灵的面具，象征隐藏的身份与真相
- **觉醒之光**：最终场景出现，象征人类意识的觉醒与自由

## 8. 场景画风前缀

### 废弃数据中心
赛博朋克风格的废弃数据中心，深蓝与暗灰色调，闪烁的应急灯提供微弱侧光，电脑屏幕发出冷蓝光，设备上覆盖着灰尘，管道和电缆交错，营造压抑神秘的氛围

### 小雅办公室
现代化科技公司办公室，月白与淡金色调，办公灯提供柔和顶光，全息屏幕投射出蓝光，整洁的桌面和专业设备，体现冷静理性的工作环境

### 安全屋
隐秘的安全屋，暗灰与霓虹绿色调，台灯提供温暖侧逆光，设备指示灯闪烁，墙上贴满代码和地图，营造紧张隐秘的氛围

### 地下数据中心
高科技地下数据中心，冰蓝与电子蓝色调，全息投影提供全方位强烈光源，服务器阵列闪烁着指示灯，机械安保巡逻，营造未来感和压迫感

### 最终觉醒场景
城市街头，温暖的自然光从天际线照射下来，色彩明亮化，监控摄像头失去光泽，人们脸上露出觉醒的表情，营造希望重生的氛围
